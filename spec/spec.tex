\section{Project Overview \& Goals}
\label{sec:overview}
% ================================================================

The Python package \texttt{fleet\_management} schedules a fleet of $F$ trains over a
horizon of $T$ days. Every day, $M$ missions must be flown. Each train flies at most
one mission, spends the day in the depot, or stays idle. Each train has $L$
components, and each component degrades stochastically. On a depot day a component
may be repaired (imperfect repair) or replaced. The schedule is a mixed-integer
program solved with Gurobi.

\textbf{Goal.} Minimise the cost of depot days, repairs and replacements, plus a
penalty on the largest train damage (Section~\ref{sec:objective}), subject to
$\Pr(D_{i\ell k} > \tau_{i\ell}) \leq \varepsilon_{i\ell}$ for every component and
every day, with $D_{i\ell k}$ the degradation and $\tau_{i\ell}$ the failure
threshold. The transitory phase ($H_1$ days) starts from the current state of the
fleet; the operating phase ($H_2$ days) is the schedule to repeat. The requirement
holds on every day of the horizon and of every later repetition of the operating
phase (Section~\ref{sec:loop}).

\textbf{Degradation models} (input \texttt{model}, one per cell):
\begin{itemize}[nosep,leftmargin=1.5em]
  \item \textbf{Gaussian}: Gaussian random walk; tracks mean and variance
        (Section~\ref{sec:dyn_gaussian}).
  \item \textbf{Inverse Gaussian (IG)}: tracks the mean; cap on the mean
        (Section~\ref{sec:dyn_ig}).
  \item \textbf{Wiener}: Brownian motion with drift; tracks mean and variance; the
        variance grows by $\sigma^2$ per mission day and falls only at a replacement
        (Section~\ref{sec:dyn_wiener}).
  \item \textbf{Gamma}: Gamma increments with mission-dependent rates; tracks the mean;
        cap on the mean (Section~\ref{sec:dyn_gamma}).
  \item \textbf{Rainflow}: distribution-free; the increment law enters through summary
        statistics; one of five tail bounds: Markov, Cantelli, Hoeffding, Bernstein,
        Chernoff (Section~\ref{sec:dyn_rainflow}).
\end{itemize}

\textbf{Repair and replacement.} Each cell has a repair law
(Section~\ref{sec:repair_laws}): $\ARDinf$ (arithmetic reduction of deterioration with
infinite memory, the default) or $\ARDone$ (arithmetic reduction of deterioration of
order 1). Every model accepts both laws. Each cell may be replaced
(Section~\ref{sec:replacement}). The loop row forces at least one replacement in the
operating phase for a Wiener cell whose train flies a mission in that phase, and for
an $\ARDone$ cell with $\rho_{i\ell} < 1$ that gains mean damage in that phase
(scoping document, section ``Stochastic loop constraint'').

\textbf{Problem class.} A mixed-integer linear program (MILP) when every reliability
row is linear and the damage penalty is \texttt{inf\_norm} or absent ($C_D = 0$);
otherwise a mixed-integer quadratically constrained program (MIQCP). It is nonconvex
when a quadratic reliability row uses the form \texttt{exact}
(Section~\ref{sec:linear_forms}), and convex when the only quadratic row is the
\texttt{quadratic} damage penalty (Section~\ref{sec:damage_reg}).

\textbf{Scope of the package.} One solve (\texttt{solve}); horizon sweeps
(Section~\ref{sec:sweeps}); warm starts (Section~\ref{sec:warm_starts}); the schedule
plot (Section~\ref{sec:plotting}); validation tools (Section~\ref{sec:validation}).
Inputs in YAML, JSON or HDF5 (Section~\ref{sec:schema}); outputs in
Section~\ref{sec:output}.

\textbf{Authority.} This specification is authoritative for the formulation and for
the tools. Every change is written here first; the code follows it.

\textbf{Non-goals.}
\begin{itemize}[nosep,leftmargin=1.5em]
  \item Routing decisions are not optimised: the missions are inputs.
  \item Continuous-time formulations are out of scope: one day is the time unit.
\end{itemize}

\subsection{Data Flow of One Solve}
\label{sec:data_flow}

\begin{lstlisting}[language=Python]
solve(input_path, results_path="output.yaml", *,
      warm_start=None, warm_start_mode="start") -> dict
\end{lstlisting}
\begin{enumerate}[nosep,label=\arabic*.]
  \item Check the input file: it exists (\texttt{FileNotFoundError}) and has the extension \texttt{.yaml}, \texttt{.yml}, \texttt{.json}, \texttt{.h5} or \texttt{.hdf5} (\texttt{ValueError}). Check \texttt{results\_path} (Section~\ref{sec:output_files}).
  \item Read the file with the input reader (Section~\ref{sec:schema}) into a mapping.
  \item \texttt{load\_config}: normalise the mapping into a \texttt{FleetConfig} and run the checks of Section~\ref{sec:consistency_checks} (\texttt{ValueError}).
  \item Build the model (Section~\ref{sec:builders}), apply the warm start (Section~\ref{sec:warm_starts}) and optimise.
  \item Extract the result (Section~\ref{sec:output}): the shared extraction, then the \texttt{extract} hook of each builder. Write the result file (Section~\ref{sec:output_files}) and return the result.
\end{enumerate}
Steps 3 to 5 form the internal entry point \texttt{solve\_mapping(data, results\_path=None, *, warm\_start=None, warm\_start\_mode="start")}, which takes the mapping of step~2. Gurobi errors are not caught.

\subsection{Public API}
\label{sec:api}

The package exports:
\begin{itemize}[nosep]
  \item one solve: \texttt{solve} (Section~\ref{sec:data_flow});
  \item horizon sweeps: \texttt{sweep\_operating\_horizons} and \texttt{sweep\_horizon\_grid} (Section~\ref{sec:sweeps});
  \item plots: \texttt{plot\_management} and \texttt{plot\_horizon\_sweep} (Section~\ref{sec:plotting});
  \item the structural validator \texttt{validate} (Section~\ref{sec:validation_structural});
  \item the Gamma validators (Section~\ref{sec:validation_gamma}): the replay validator \texttt{validate\_gamma\_replay\_schedule} with its file version \texttt{validate\_gamma\_replay\_files}; the Monte Carlo validator \texttt{validate\_gamma\_stochastic\_schedule}; and the selector of both, \texttt{validate\_gamma\_schedule}, with its file version \texttt{validate\_gamma\_schedule\_files}.
\end{itemize}
Internal functions, not exported: \texttt{solve\_mapping} and \texttt{load\_config} (Section~\ref{sec:data_flow}); the greedy heuristic \texttt{build\_greedy\_warm\_start} (Section~\ref{sec:greedy}); the exact Gamma validator \texttt{validate\_gamma\_tail\_bound\_schedule} and its file version (Section~\ref{sec:validation_gamma}).

\subsection{Cell-Builder Interface}
\label{sec:builders}

A registry maps each model name (\texttt{gaussian}, \texttt{inverse\_gaussian}, \texttt{wiener}, \texttt{gamma}, \texttt{rainflow}) to a builder; the model of cell $(i,\ell)$ is its entry of \texttt{model}.
\begin{lstlisting}[language=Python]
register_cell_builder(name, builder)  # CELL_BUILDERS[name] = builder
get_cell_builder(name)    # NotImplementedError, with the names, if absent
dispatch_cell(ctx, i, l)  # get_cell_builder(ctx.model_of[i, l])
                          #     .add_cell(ctx, i, l)
\end{lstlisting}
A builder has the attribute \texttt{name} and three hooks:
\begin{itemize}[nosep]
  \item \texttt{prepare(ctx, cfg, cells, opts)}: called once per model in the fleet, with its cells. It stores the per-cell arrays of the model in \texttt{ctx}, creates the variables of the tracked quantities other than the shared mean $\mu$, and of the anchors and selectors, of these cells only, may tighten variable bounds, and sets Gurobi's \texttt{NonConvex} to $2$ if some cell keeps an exact quadratic row.
  \item \texttt{add\_cell(ctx, i, l)}: adds the rows of one cell (Section~\ref{sec:constraints}): dynamics in the form of \texttt{encoding}, replacement and anchor rows, repair-cost rows, reliability rows in the form of \texttt{reliability\_impl}, loop rows of the full tracked state.
  \item \texttt{extract(ctx, cfg, out)}, optional: adds model-specific entries to the result \texttt{out} after the shared entries.
\end{itemize}
The context \texttt{ctx} holds the sizes $F$, $L$, $M$, $H_1$, $H_2$, $T$; the Gurobi model; the shared variables $x$, $x^m$, $x^r$ (absent if replacement is not allowed), $\mu$, $z$ (cells with $C_R > 0$) and $u$ (if $C_D > 0$), with the shapes of Section~\ref{sec:variables}; the per-cell arrays (model, $\tau$, $\varepsilon$, $\rho$, initial and replacement values, starting anchors); the increment accessor $(i, j, \ell, k) \mapsto$ increment after the phase lookup, Eq.~\eqref{eq:c_phase}, with $j = 0$ the depot; the run options; a dictionary \texttt{extras}.

Building order:
\begin{enumerate}[nosep,label=\arabic*.]
  \item Create the model, apply the run options, create the shared variables.
  \item Call \texttt{prepare} for each model present, in alphabetical order of the names.
  \item Build the objective (Section~\ref{sec:objective}) and the rows that do not depend on the model: assignment (Section~\ref{sec:assignment}), depot day (Section~\ref{sec:depot}), damage penalty (Section~\ref{sec:damage_reg}).
  \item Call \texttt{add\_cell} for every cell, $i$ outer, $\ell$ inner.
\end{enumerate}
Each builder defines $\mu_{i\ell k}$, $k = 1,\ldots,T$, for its cells. A model is added by a module with its builder, its registration, its input checks in \texttt{config.py} (Section~\ref{sec:consistency_checks}) and its section in this specification.

\section{Input Specification}\label{sec:inputs}

An input is one mapping from key names to values.
A \emph{cell} is a pair $(i,\ell)$ of a train and a component.
The column \emph{Applies to} uses the abbreviations G (Gaussian), IG (inverse Gaussian), W (Wiener), Ga (Gamma), RF (rainflow) and, for a rainflow cell, Mk (Markov), Ca (Cantelli), Ho (Hoeffding), Be (Bernstein), Ch (Chernoff); \emph{all} is every cell.
A \emph{cell value} is a scalar, a list of $L$ numbers (one per component, copied to every train) or an $F \times L$ array; a scalar is copied to every cell.
A \emph{selector} has the same shapes with strings.
A \emph{profile} is defined in Section~\ref{sec:input_increments}; a \emph{flag} is \texttt{true} or \texttt{false}.
No other broadcasting is accepted.

At a cell where a key does not apply, an array entry may be \texttt{null} and the key may be omitted; where it applies, \texttt{null} is an error.
The exceptions are the three keys without a default, \texttt{v\_max\_user}, \texttt{gamma\_beta\_0} and \texttt{gamma\_beta\_new}: at these keys, \texttt{null} at a cell means that the key is not given at that cell.
A broadcast value (a scalar, a list, a profile without the axis $F$) is read only where the key applies.
A non-\texttt{null} entry of an array with one entry per cell ($F \times L$ array, or profile with the axes $F$ and $L$) at a cell where the key does not apply is ignored with a \texttt{UserWarning}; a selector entry there is still checked (Section~\ref{sec:consistency_checks}).
Key names and selector values are case sensitive; a key outside the tables raises an error (Section~\ref{sec:input_rejected}).
An integer key accepts a number with zero fractional part, such as \texttt{3.0}; it refuses any other number, such as \texttt{2.5}, and a flag.

\subsection{Increment Profiles and the Phase Lookup}\label{sec:input_increments}

A profile gives a parameter of the damage increment when train $i$ flies mission $j \in \{1,\ldots,M\}$, for component $\ell$.
Its canonical shape is $(F, L, M, H_*)$, with $H_* = H_2$ for an operating profile and $H_* = H_1$ for a transitory profile.
The parser accepts the shapes scalar, $(M)$, $(L, M)$, $(L, M, H_*)$, $(F, L, M)$ and $(F, L, M, H_*)$, and expands each of them to $(F, L, M, H_*)$ before any row is built (eager broadcasting); a missing axis is repeated.
An array whose shape fits both $(L, M, H_*)$ and $(F, L, M)$ is read as $(L, M, H_*)$.
\texttt{gamma\_beta} and \texttt{gamma\_beta\_trans} read a list as one rate per component and a two-dimensional array as one rate per cell; rates per mission have the shape $(F, L, M)$.

Let $p$ be an operating profile and $p^{\tr}$ the transitory profile of the same key, if given.
The value used on day $k \in \{1,\ldots,T\}$ is
\begin{equation}\label{eq:c_phase}
p^{\inc}_{i\ell jk} =
\begin{cases}
p^{\tr}_{i\ell jk} & k \le H_1 \text{ and } p^{\tr} \text{ is given},\\[2pt]
p_{i\ell j,\,((k-1) \bmod H_2) + 1} & k \le H_1 \text{ and } p^{\tr} \text{ is not given},\\[2pt]
p_{i\ell j,\,((k-H_1-1) \bmod H_2) + 1} & k > H_1.
\end{cases}
\end{equation}
Each profile key is looked up on its own.
The symbols $\mu^{\inc}_{i\ell jk}$, $v^{\inc}_{i\ell jk}$, $b^{\inc}_{i\ell jk}$ and $K^{\inc}_{i\ell jk}$ denote the values after the lookup.

\subsection{Consistency Checks}\label{sec:consistency_checks}

The solver validates all of the following before it builds the model.
A violation raises a \texttt{ValueError} whose message names the key and, for a cell value, the cell $(i,\ell)$.
A check of one model runs only at the cells of that model, on the entries where the key applies.
A non-strict inequality $a \le b$ (or $a \ge b$) passes when it holds up to $10^{-12}\max(1, |a|, |b|)$; a strict inequality has no tolerance.

\textbf{Keys, shapes and entries.}
\begin{itemize}[leftmargin=1.5em]
  \item Every key is in the tables of Section~\ref{sec:inputs}. The keys \texttt{F}, \texttt{M}, \texttt{H}, \texttt{model}, \texttt{tau}, \texttt{epsilon}, \texttt{rho}, \texttt{mu\_0}, \texttt{mu}, \texttt{C\_M}, \texttt{C\_R}, \texttt{C\_rep}, \texttt{C\_D} and the keys that each cell type requires (Section~\ref{sec:schema}) are present.
  \item Each value has one of the shapes of its table row; the last axis of an operating profile has $H_2$ entries and that of a transitory profile $H_1$; \texttt{component\_names} has $L$ entries.
  \item At a cell where a key applies, every entry is a finite number (a string for a selector); \texttt{null} is an error.
\end{itemize}

\textbf{Sizes and selectors.}
\begin{itemize}[leftmargin=1.5em]
  \item $F$, $M$ and $L$ are positive integers, and $F > M$. A given \texttt{L} equals the length of the component axis of \texttt{model} when \texttt{model} is a list or an array.
  \item Every entry of \texttt{component\_names} is a string that is not empty after blanks are removed.
  \item $H$ is an integer $\ge 1$, or a pair of integers $H_1, H_2 \ge 1$.
  \item \texttt{model} entries are \texttt{gaussian}, \texttt{inverse\_gaussian}, \texttt{wiener}, \texttt{gamma} or \texttt{rainflow}; \texttt{repair\_model} entries are \texttt{ard1} or \texttt{ardinf}, for every model.
  \item Every non-\texttt{null} entry of \texttt{bound\_method} is \texttt{markov}, \texttt{cantelli}, \texttt{hoeffding}, \texttt{bernstein} or \texttt{chernoff}, also at a cell that is not rainflow.
  \item Every non-\texttt{null} entry of \texttt{reliability\_impl} is \texttt{exact}, \texttt{tangent} or \texttt{pwl}, also at a cell whose row is linear (IG, Ga, Mk, Ch); there the value is ignored and the form \texttt{exact} is built. \texttt{encoding} entries are \texttt{bigm} or \texttt{indicator}.
  \item \texttt{penalty\_type} is \texttt{inf\_norm} or \texttt{quadratic}. If $C_D > 0$ and \texttt{penalty\_type} is \texttt{quadratic}, \texttt{reliability\_impl} is \texttt{exact} at every cell with a quadratic reliability row (G, W, and RF with Ca, Ho or Be); another value is an error.
\end{itemize}

\textbf{Reliability, repair and initial state.}
\begin{itemize}[leftmargin=1.5em]
  \item $\tau_{i\ell} > 0$ and finite.
  \item $\varepsilon_{i\ell} \in (0, 1)$, and $\varepsilon_{i\ell} < 0.5$ at G and W cells.
  \item $\rho_{i\ell} \in (0, 1]$.
  \item $0 \le \mu_{0,i\ell} < \tau_{i\ell}$.
  \item $v_0$, \texttt{support\_0} and $R_0$ are $\ge 0$; if \texttt{allow\_replacement} is \texttt{true}, so are \texttt{replacement\_mu}, \texttt{replacement\_v}, \texttt{support\_new} and $R^{\new}$.
  \item \texttt{tangent\_ref} $\in [0, 1)$ at cells with the form \texttt{tangent}; \texttt{pwl\_points} is an integer $\ge 1$.
  \item Starting anchors: $0 \le \texttt{anchor\_mu\_0} \le \mu_0$, $0 \le \texttt{anchor\_v\_0} \le v_0$, $0 \le \texttt{anchor\_R\_0} \le R_0$ and $0 \le \texttt{anchor\_K\_0} \le K_0$, at the cells that read them.
  \item If \texttt{replacement\_as\_new} is \texttt{true}, \texttt{replacement\_mu}, \texttt{replacement\_v}, \texttt{support\_new}, \texttt{R\_new} and \texttt{cgf\_new} are $0$ at every cell that reads them; the check does not run when the flag is \texttt{false}.
\end{itemize}

\textbf{Natural ranges and replacement states.}
\begin{itemize}[leftmargin=1.5em]
  \item Every initial value ($\mu_0$, $v_0$, $R_0$, $K_0$) and every replacement value ($\mu^{\new}$, $v^{\new}$, $R^{\new}$, $K^{\new}$; only if \texttt{allow\_replacement} is \texttt{true}) lies in $[0, M_s]$, with the natural range $M_s$ of its state: $\tau$ for a mean; $V_{\max} = \tau^2/\bigl(\Phi^{-1}(1-\varepsilon)\bigr)^2$ for the variance at G and W cells; $\varepsilon\tau^2/(1-\varepsilon)$ at Ca cells; $\tau(\tau - 2c)/(2\kappa)$ at Be cells, with $c = \kappa b/3$ and $\kappa = \ln(1/\varepsilon)$; $2\tau^2/\kappa$ for $R$ at Ho cells; $s\tau - \kappa$ for $K$ at Ch cells (Sections~\ref{sec:dyn_gaussian} to~\ref{sec:dyn_rainflow}). Hence every starting anchor lies in its range.
  \item If \texttt{allow\_replacement} is \texttt{true}, the replacement state $(\mu^{\new}, v^{\new}, R^{\new}, K^{\new})$ of every cell satisfies every row that holds on a replacement day, in the form built at the cell: the reliability row in the form of \texttt{reliability\_impl} (for \texttt{pwl}, the cap of the segment that contains $\mu^{\new}$), its side row, and $v^{\new} \le V^{\mathrm{user}}_{\max,i\ell}$ where \texttt{v\_max\_user} is given (Sections~\ref{sec:dyn_gaussian} to~\ref{sec:dyn_rainflow} and~\ref{sec:linear_forms}).
\end{itemize}

\textbf{Increments.}
\begin{itemize}[leftmargin=1.5em]
  \item $0 \le \mu^{\inc}_{i\ell jk} < \tau_{i\ell}$ for every mission $j$ and every day $k \in \{1,\ldots,T\}$.
  \item Where $\mu^{\inc}_{i\ell jk} = 0$, the values $v^{\inc}_{i\ell jk}$, $b^{\inc}_{i\ell jk}$ and $K^{\inc}_{i\ell jk}$ are $0$.
  \item $v^{\inc}_{i\ell jk}$, $b^{\inc}_{i\ell jk}$ and $K^{\inc}_{i\ell jk}$ are $\ge 0$. A transitory profile has its operating profile.
\end{itemize}

\textbf{Gaussian, inverse Gaussian, Wiener and Gamma cells.}
\begin{itemize}[leftmargin=1.5em]
  \item G: $\mu_0 \ge 3\sqrt{v_0}$, $\mu^{\inc}_{i\ell jk} \ge 3\sqrt{v^{\inc}_{i\ell jk}}$ for every mission $j$ and day $k$, and, if \texttt{allow\_replacement} is \texttt{true}, $\mu^{\new} \ge 3\sqrt{v^{\new}}$.
  \item IG: $\eta_{i\ell} > 0$.
  \item W: $\sigma_{i\ell} > 0$ and $v_{0,i\ell} \ge 0$.
  \item Ga: every entry of \texttt{gamma\_beta} and \texttt{gamma\_beta\_trans} is finite and $> 0$; \texttt{gamma\_beta\_0} and \texttt{gamma\_beta\_new}, where given, are finite and $> 0$.
  \item G, W, RF (Ca, Be) with \texttt{v\_max\_user} given: $V^{\mathrm{user}}_{\max,i\ell} > 0$, $V^{\mathrm{user}}_{\max,i\ell} \ge v_{0,i\ell}$ and, if \texttt{allow\_replacement} is \texttt{true}, $V^{\mathrm{user}}_{\max,i\ell} \ge v^{\new}_{i\ell}$.
\end{itemize}

\textbf{Rainflow cells.}
\begin{itemize}[leftmargin=1.5em]
  \item Be: $v^{\inc}_{i\ell jk} \le (b^{\inc}_{i\ell jk})^2/4$ for every mission $j$ and day $k$, $v_{0} \le (b^{0})^2/4$ and, if \texttt{allow\_replacement} is \texttt{true}, $v^{\new} \le (b^{\new})^2/4$.
  \item Be: $\tau_{i\ell} > 2\kappa\, b_{i\ell}/3$, with $\kappa = \ln(1/\varepsilon_{i\ell})$ and $b_{i\ell}$ the support constant of Section~\ref{sec:dyn_rainflow}.
  \item Be with the form \texttt{tangent}: $\texttt{tangent\_ref}\cdot\tau_{i\ell} < \sqrt{\tau_{i\ell}\,(\tau_{i\ell} - 2c_{i\ell})}$, with $c_{i\ell} = \kappa\, b_{i\ell}/3$; Be with the form \texttt{pwl}: $\tau_{i\ell}/(2P) < \sqrt{\tau_{i\ell}\,(\tau_{i\ell} - 2c_{i\ell})}$, with $P = \texttt{pwl\_points}$.
  \item Ch: \texttt{s\_chernoff} is given and $s_{i\ell} > \ln(1/\varepsilon_{i\ell})/\tau_{i\ell}$.
  \item Ch: $K^{\inc}_{i\ell jk} \ge s_{i\ell}\,\mu^{\inc}_{i\ell jk}$ for every mission $j$ and day $k$, $K_{0} \ge s\,\mu_{0}$, at \texttt{ard1} cells $g^{K}_{0} \ge s\,g^{\mu}_{0}$, and, if \texttt{allow\_replacement} is \texttt{true}, $K^{\new} \ge s\,\mu^{\new}$.
\end{itemize}

\textbf{Run options and costs.}
\begin{itemize}[leftmargin=1.5em]
  \item \texttt{objective\_mode} is \texttt{total}, \texttt{operating\_average} or \texttt{evaluation\_total}; in the last mode \texttt{evaluation\_horizon} is given. If \texttt{evaluation\_horizon} is given, in any mode, it is an integer $E > H_1$.
  \item \texttt{mip\_gap} $\ge 0$; a value below $0$ that passes through the tolerance is set to $0$, because Gurobi refuses a negative gap; \texttt{time\_limit}, \texttt{progress\_interval\_seconds} and \texttt{relaxation\_time\_limit} are $> 0$; \texttt{gurobi\_params} and \texttt{validation} are mappings; \texttt{fast}, \texttt{relaxation\_warm\_start}, \texttt{allow\_replacement} and \texttt{replacement\_as\_new} are flags.
  \item $C_M$, $C_D$, $C_{R,i\ell}$ and $C_{\mathrm{rep},i\ell}$ are finite and $\ge 0$.
\end{itemize}

\section{Objective Function}
\label{sec:objective}
% ================================================================

Cost of day $k$, and costs of the two phases:
\begin{equation}
  c_k = C_M \sum_{i=1}^{F} x_{i0k}
      + \sum_{i=1}^{F}\sum_{\ell=1}^{L} C_{R,i\ell}\, z_{i\ell k}
      + \sum_{i=1}^{F}\sum_{\ell=1}^{L} C_{\mathrm{rep},i\ell}\, x^r_{i\ell k},
  \label{eq:a_daycost}
\end{equation}
\begin{equation}
  J_{\mathrm{init}} = \sum_{k=1}^{H_1} c_k, \qquad
  J_{\mathrm{op}} = \sum_{k=H_1+1}^{T} c_k .
  \label{eq:a_phases}
\end{equation}
$z_{i\ell k}$ reads $0$ where it is not built; the last sum of $c_k$ is absent when
\texttt{allow\_replacement = false}. The input \texttt{objective\_mode} (default
\texttt{total}) selects the objective:
\begin{equation}
  \min\;
  \begin{cases}
    J_{\mathrm{init}} + J_{\mathrm{op}} + C_D\, u & \texttt{total}, \\[2pt]
    J_{\mathrm{op}} / H_2 + C_D\, u & \texttt{operating\_average}, \\[2pt]
    J_{\mathrm{init}} + \dfrac{E - H_1}{H_2}\, J_{\mathrm{op}} + C_D\, u
      & \texttt{evaluation\_total},
  \end{cases}
  \label{eq:a_objective}
\end{equation}
with $E$ the input \texttt{evaluation\_horizon}, required in the mode
\texttt{evaluation\_total}, $E > H_1$. The term $C_D\,u$ is present only when
$C_D > 0$.

\textbf{Cost terms} (shapes in Section~\ref{sec:inputs}).
\begin{itemize}[nosep,leftmargin=1.5em]
  \item $C_M \geq 0$, scalar: paid once per train per depot day ($x_{i0k} = 1$),
        whatever the number of interventions on that day. An idle day costs nothing.
  \item $C_{R,i\ell} \geq 0$: per unit of mean degradation removed by a repair
        (Section~\ref{sec:repair_cost}).
  \item $C_{\mathrm{rep},i\ell} \geq 0$: per replacement; required, no default.
  \item $C_D \geq 0$: weight of $u$ (Section~\ref{sec:damage_reg}); the term is added
        once in every mode.
\end{itemize}

% ================================================================
\section{Constraints}
\label{sec:constraints}
% ================================================================

Every row holds for every day $k = 1, \ldots, T$ unless its section says otherwise.

\subsection{Assignment Constraints}
\label{sec:assignment}

Each train performs at most one activity per day:
\begin{equation}
  \sum_{j=0}^{M} x_{ijk} \leq 1 \qquad \forall\, i, k .
  \label{eq:a_one_activity}
\end{equation}
Each mission is flown by exactly one train every day:
\begin{equation}
  \sum_{i=1}^{F} x_{ijk} = 1 \qquad \forall\, j \in \{1, \ldots, M\},\; k .
  \label{eq:a_coverage}
\end{equation}
Exactly $M$ trains fly every day; the other $F - M$ trains are in the depot or idle.
No other fleet-availability row is built. An idle day is an all-zero assignment row.
Depot days and idle days add no increment.

\subsection{Depot-Day Compatibility}
\label{sec:depot}

A component may be repaired or replaced only on a depot day of its train, and at most
one of the two on the same day:
\begin{equation}
  x^m_{i\ell k} + x^r_{i\ell k} \leq x_{i0k} \qquad \forall\, i, \ell, k .
  \label{eq:a_depot}
\end{equation}
With \texttt{allow\_replacement = false} the row reads $x^m_{i\ell k} \leq x_{i0k}$.
Several components of one train may receive interventions on the same depot day; a
component without an intervention keeps its state.

\subsection{Repair Laws}
\label{sec:repair_laws}

The input \texttt{repair\_model} selects the law per cell (default \texttt{ardinf});
the repair efficiency is $\rho = \rho_{i\ell} \in (0, 1]$. With $D^-$ the degradation
before a repair on day $k$ (end of day $k-1$) and $D^+$ the degradation after it:
\begin{align}
  \ARDinf\ (\texttt{ardinf}):&\quad D^+ = (1-\rho)\, D^- ,
    \label{eq:a_ardinf} \\
  \ARDone\ (\texttt{ard1}):&\quad D^+ = D^- - \rho\,\bigl(D^- - D^{\mathrm{last}}\bigr),
    \label{eq:a_ard1}
\end{align}
with $D^{\mathrm{last}}$ the level just after the last intervention (repair or
replacement); before the first intervention of the horizon, the level just after the
last intervention before it. Every model accepts both laws.

\textbf{Repair map.} For a tracked quantity $s$ with anchor $g$, a repair on day $k$
gives
\begin{equation}
  \psi(s_{k-1}, g_{k-1}) =
  \begin{cases}
    a\, s_{k-1} & \ARDinf, \\
    a\, s_{k-1} + (1-a)\, g_{k-1} & \ARDone,
  \end{cases}
  \label{eq:a_psi}
\end{equation}
with the repair factor $a = 1 - \rho$ for a mean and for $K$, $a = (1-\rho)^2$ for a
variance and for $R$, and $a = 1$ for the Wiener variance (both laws). The model
sections give the factor of each tracked quantity.

\textbf{Anchors} ($\ARDone$ only; one per tracked quantity, none for the Wiener
variance):
\begin{equation}
  g_0 = \text{starting anchor}, \qquad
  g_k = \begin{cases}
    s_k & \text{on a repair or replacement day}, \\
    g_{k-1} & \text{otherwise}.
  \end{cases}
  \label{eq:a_anchor}
\end{equation}
The starting anchors $g^{\mu}_{i\ell 0}$, $g^{v}_{i\ell 0}$, $g^{R}_{i\ell 0}$,
$g^{K}_{i\ell 0}$ are the optional inputs \texttt{anchor\_mu\_0}, \texttt{anchor\_v\_0},
\texttt{anchor\_R\_0}, \texttt{anchor\_K\_0}; the default of each is the initial value
of its quantity; each satisfies $0 \leq g_0 \leq s_0$
(Section~\ref{sec:consistency_checks}).

\subsection{Encoding of the Dynamics}
\label{sec:encoding}

Every dynamics row is one-sided ($\geq$); replacement rows and anchor rows are
equalities. For one tracked quantity $s$ of a cell (a mean, a variance, $R$ or $K$):
day increment $\delta s_k$, natural range $M_s$, replacement value $s^{\new}$, anchor
$g$ ($\ARDone$ only), repair map $\psi$ (Eq.~\eqref{eq:a_psi}), cell binaries $x^m_k$,
$x^r_k$, and $e_k = x^m_k + x^r_k$. The input \texttt{encoding} selects the form per
cell.

\emph{Big-M form} (\texttt{encoding = "bigm"}, the default):
\begin{align}
  &\text{no intervention:} & s_k &\geq s_{k-1} + \delta s_k - M_s\,(x^m_k + x^r_k),
    \label{eq:a_bigm_carry} \\
  &\text{repair:} & s_k &\geq \psi(s_{k-1}, g_{k-1}) - M_s\,(1 - x^m_k),
    \label{eq:a_bigm_repair} \\
  &\text{replacement:} & |s_k - s^{\new}| &\leq M_s\,(1 - x^r_k),
    \label{eq:a_bigm_repl} \\
  &\text{anchor } (\ARDone)\text{:} & |g_k - s_k| &\leq M_s\,(1 - e_k), \qquad
    |g_k - g_{k-1}| \leq M_s\, e_k .
    \label{eq:a_bigm_anchor}
\end{align}
Each row with an absolute value is built as two linear rows.

\emph{Indicator form} (\texttt{encoding = "indicator"}). One binary $n_{i\ell k}$ per
cell and day, and Gurobi indicator constraints:
\begin{equation}
  n_{i\ell k} + x^m_{i\ell k} + x^r_{i\ell k} = 1 ,
  \label{eq:a_ind_sum}
\end{equation}
\begin{align}
  n_k = 1 &\;\Rightarrow\; s_k \geq s_{k-1} + \delta s_k, &
  x^m_k = 1 &\;\Rightarrow\; s_k \geq \psi(s_{k-1}, g_{k-1}), &
  x^r_k = 1 &\;\Rightarrow\; s_k = s^{\new}, \label{eq:a_ind_state} \\
  n_k = 1 &\;\Rightarrow\; g_k = g_{k-1}, &
  x^m_k = 1 &\;\Rightarrow\; g_k = s_k, &
  x^r_k = 1 &\;\Rightarrow\; g_k = s_k. \label{eq:a_ind_anchor}
\end{align}

\emph{Rules for both forms.}
\begin{itemize}[nosep,leftmargin=1.5em]
  \item Anchor rows only under $\ARDone$, for every tracked quantity except the Wiener
        variance.
  \item Wiener variance: $\psi = s_{k-1}$, no anchor; it is never left free below on
        a repair day. In the big-M form its no-intervention and repair rows are
        replaced by the single row Eq.~\eqref{eq:w_vrow}.
  \item \texttt{allow\_replacement = false}: no $x^r$; read $x^r_k = 0$ and drop the
        replacement rows.
  \item At binary points the two forms have the same feasible set.
\end{itemize}

\textbf{Natural ranges} $M_s$ (big-M constants): $\tau_{i\ell}$ for a mean;
$V_{\max}$ for a Gaussian or Wiener variance; $V^{\mathrm{C}}$ or $V^{\mathrm{B}}$ for
a rainflow variance (Cantelli or Bernstein); $2\tau^2/\kappa$ for $R$;
$s_{i\ell}\tau - \kappa$ for $K$ (Section~\ref{sec:dyn_rainflow}). An anchor has the
range of its quantity.

\subsection{Replacement}
\label{sec:replacement}

The input \texttt{allow\_replacement} (default \texttt{true}) makes replacements
available; when \texttt{false}, the binaries $x^r_{i\ell k}$, the replacement rows and
the replacement cost are not built. On a replacement day every tracked quantity of
the cell takes its replacement value, and every anchor the same value:
\begin{itemize}[nosep,leftmargin=1.5em]
  \item $\mu^{\new}_{i\ell}$: input \texttt{replacement\_mu}, default $0$;
  \item $v^{\new}_{i\ell}$: input \texttt{replacement\_v}, default $0$, where a
        variance is tracked;
  \item $R^{\new}_{i\ell}$, $K^{\new}_{i\ell}$: rainflow Hoeffding and Chernoff,
        Section~\ref{sec:dyn_rainflow}.
\end{itemize}
The rows are Eq.~\eqref{eq:a_bigm_repl} or Eq.~\eqref{eq:a_ind_state}. Each
replacement value lies in the natural range of its quantity, and the replacement
state satisfies every row of a replacement day in the form built at the cell
(Section~\ref{sec:consistency_checks}).

The input \texttt{replacement\_as\_new} (default \texttt{false}) sets every replacement
value of the cell to $0$; a non-zero replacement input together with it is an input
error. A replacement costs $C_{\mathrm{rep},i\ell}$ only ($z_{i\ell k} = 0$ on a
replacement day). A cell may be replaced on any depot day, any number of times.

\subsection{Linear Forms of the Reliability Rows}
\label{sec:linear_forms}

The Gaussian, Wiener, Cantelli, Hoeffding and Bernstein rows have the form
\begin{equation}
  \chi_{i\ell k} \;\leq\; f(\mu_{i\ell k}),
  \qquad f(\mu) = c_2\,(\tau - \mu)^2 + c_1\,(\tau - \mu),
  \qquad \mu_{i\ell k} \leq \bar\mu_{\mathrm{side}},
  \label{eq:a_quad}
\end{equation}
with $f'(\mu) = -2c_2(\tau - \mu) - c_1$; the third relation is the side row.

\begingroup\small
\begin{longtable}{@{}lllll@{}}
\toprule
Row & $\chi$ & $c_2$ & $c_1$ & $\bar\mu_{\mathrm{side}}$ \\
\midrule
Gaussian, Wiener & $v$ & $1/\kappa_G^2$ & $0$ & $\tau$ \\
Rainflow, Cantelli & $v$ & $1/\kappa_C^2 = \varepsilon/(1-\varepsilon)$ & $0$ & $\tau$ \\
Rainflow, Hoeffding & $R$ & $2/\kappa$ & $0$ & $\tau$ \\
Rainflow, Bernstein & $v$ & $1/(2\kappa)$ & $-b_{i\ell}/3$ & $\tau - c_{i\ell}$ \\
\bottomrule
\end{longtable}
\endgroup

The input \texttt{reliability\_impl} selects the form per cell; every form keeps the
side row.
\begin{itemize}[leftmargin=1.5em]
  \item \texttt{exact}: Eq.~\eqref{eq:a_quad}, a nonconvex quadratic constraint.
        Gurobi's \texttt{NonConvex} is set to $2$ when at least one cell has a
        quadratic row in this form.
  \item \texttt{tangent}: one linear row per day, at
        $\mu_r = \texttt{tangent\_ref}_{i\ell}\cdot\tau_{i\ell}$ (\texttt{tangent\_ref}
        per cell, in $[0, 1)$, default $0.5$):
        \begin{equation}
          \chi_{i\ell k} \;\leq\; f(\mu_r) + f'(\mu_r)\,(\mu_{i\ell k} - \mu_r).
          \label{eq:a_tangent}
        \end{equation}
        At a Bernstein cell, $\mu_r < \sqrt{\tau\,(\tau - 2c_{i\ell})}$
        (Section~\ref{sec:consistency_checks}).
  \item \texttt{pwl}: $P = \texttt{pwl\_points}$ equal segments
        $[(p-1)\tau/P,\; p\tau/P]$ of $[0, \tau]$ (default $P = 8$), midpoints
        $\hat\mu_p = (p - \tfrac12)\tau/P$, and one binary $w_{i\ell kp}$ per cell,
        day and segment:
        \begin{align}
          \textstyle\sum_{p=1}^{P} w_{i\ell kp} &= 1, \label{eq:a_pwl_sum} \\
          w_{i\ell kp} = 1 &\;\Rightarrow\;
            (p-1)\,\tau/P \leq \mu_{i\ell k} \leq p\,\tau/P, \label{eq:a_pwl_seg} \\
          w_{i\ell kp} = 1 &\;\Rightarrow\;
            \chi_{i\ell k} \leq f(\hat\mu_p) + f'(\hat\mu_p)\,(\mu_{i\ell k} - \hat\mu_p).
            \label{eq:a_pwl_cap}
        \end{align}
        The implications are Gurobi indicator constraints in both encodings. With
        $P = 1$: the single tangent at $\tau/2$, no binaries. At a Bernstein cell,
        $\tau/(2P) < \sqrt{\tau\,(\tau - 2c_{i\ell})}$
        (Section~\ref{sec:consistency_checks}).
\end{itemize}
At a cell whose reliability row is linear (Markov, Chernoff, inverse Gaussian, Gamma)
the row is built in its exact form and the value of \texttt{reliability\_impl} is
ignored. An unknown value is an input error at every cell. Each linear form implies
the exact row (scoping document, section ``Linear forms of the reliability rows'').

% ----------------------------------------------------------------
\subsection{Gaussian Model}
\label{sec:dyn_gaussian}
% ----------------------------------------------------------------

For cells $(i,\ell)$ with \texttt{model} $=$ \texttt{gaussian}. In this section and
the next four, the subscript $i\ell$ is dropped and $k$ is the day.

\textbf{Model.} A mission increment is $\mathcal{N}(\mu^{\inc}_{jk}, v^{\inc}_{jk})$
(inputs \texttt{mu}, \texttt{v}); the initial damage is $\mathcal{N}(\mu_0, v_0)$; a
replacement draw is $\mathcal{N}(\mu^{\new}, v^{\new})$. A known damage has variance 0.
\textbf{Assumption N1.} The increments, the initial damage and the replacement draws
are mutually independent.

\textbf{Laws and tracked quantities.} $\ARDinf$ and $\ARDone$. Tracked: $\mu_k$ and
$v_k$; under $\ARDone$ also the anchors $g^{\mu}_k$ and $g^{v}_k$. Day maps:
\begin{align}
  \mu_k &= \begin{cases}
    \mu_{k-1} + \delta\mu_k & \text{no intervention on day } k,\\
    (1-\rho)\,\mu_{k-1} & \text{repair, } \ARDinf,\\
    (1-\rho)\,\mu_{k-1} + \rho\, g^{\mu}_{k-1} & \text{repair, } \ARDone,\\
    \mu^{\new} & \text{replacement,}
  \end{cases}
  \label{eq:g_map_mu} \\
  v_k &= \begin{cases}
    v_{k-1} + \delta v_k & \text{no intervention on day } k,\\
    (1-\rho)^2\, v_{k-1} & \text{repair, } \ARDinf,\\
    (1-\rho)^2\, v_{k-1} + \bigl(1 - (1-\rho)^2\bigr)\, g^{v}_{k-1}
      & \text{repair, } \ARDone,\\
    v^{\new} & \text{replacement,}
  \end{cases}
  \label{eq:g_map_v}
\end{align}
with $\delta\mu_k = \sum_{j=1}^{M} x_{ijk}\,\mu^{\inc}_{jk}$ and
$\delta v_k = \sum_{j=1}^{M} x_{ijk}\,v^{\inc}_{jk}$.

\textbf{Big-M rows} (\texttt{encoding = "bigm"}, the default). In this section and
the next four, each row holds for $k = 1, \ldots, T$, and $e_k = x^m_k + x^r_k$. The
$\ARDinf$ rows are built at $\ARDinf$ cells; the $\ARDone$ rows and the anchor rows at
$\ARDone$ cells. With \texttt{allow\_replacement = false}, $x^r_k = 0$ and the
replacement rows are not built. Big-M constants: $\tau$ for $\mu$ and $g^{\mu}$;
$V_{\max} = \tau^2/\kappa_G^2$ for $v$ and $g^{v}$, with
$\kappa_G = \Phi^{-1}(1-\varepsilon)$.

\emph{Mean.}
\begin{align}
  &\text{no intervention:} & \mu_k &\geq \mu_{k-1} + \delta\mu_k - \tau\,(x^m_k + x^r_k),
    \label{eq:g_mu_carry} \\
  &\text{repair, } \ARDinf\text{:} & \mu_k &\geq (1-\rho)\,\mu_{k-1} - \tau\,(1 - x^m_k),
    \label{eq:g_mu_inf} \\
  &\text{repair, } \ARDone\text{:} & \mu_k &\geq (1-\rho)\,\mu_{k-1} + \rho\, g^{\mu}_{k-1}
    - \tau\,(1 - x^m_k),
    \label{eq:g_mu_one} \\
  &\text{replacement:} & \mu_k &\geq \mu^{\new} - \tau\,(1 - x^r_k), \quad
    \mu_k \leq \mu^{\new} + \tau\,(1 - x^r_k).
    \label{eq:g_mu_repl}
\end{align}

\emph{Variance.}
\begin{align}
  &\text{no intervention:} & v_k &\geq v_{k-1} + \delta v_k - V_{\max}\,(x^m_k + x^r_k),
    \label{eq:g_v_carry} \\
  &\text{repair, } \ARDinf\text{:} & v_k &\geq (1-\rho)^2\, v_{k-1}
    - V_{\max}\,(1 - x^m_k),
    \label{eq:g_v_inf} \\
  &\text{repair, } \ARDone\text{:} & v_k &\geq (1-\rho)^2\, v_{k-1}
    + \bigl(1 - (1-\rho)^2\bigr)\, g^{v}_{k-1} - V_{\max}\,(1 - x^m_k),
    \label{eq:g_v_one} \\
  &\text{replacement:} & v_k &\geq v^{\new} - V_{\max}\,(1 - x^r_k), \quad
    v_k \leq v^{\new} + V_{\max}\,(1 - x^r_k).
    \label{eq:g_v_repl}
\end{align}

\emph{Anchors} ($\ARDone$), for $(y, M_y) \in \{(\mu, \tau),\, (v, V_{\max})\}$:
\begin{align}
  g^{y}_k - y_k &\leq M_y\,(1 - e_k), & y_k - g^{y}_k &\leq M_y\,(1 - e_k),
    \label{eq:g_anchor_set} \\
  g^{y}_k - g^{y}_{k-1} &\leq M_y\, e_k, & g^{y}_{k-1} - g^{y}_k &\leq M_y\, e_k.
    \label{eq:g_anchor_keep}
\end{align}

\emph{Day 0 and replacement.} The constants $\mu_0$, $v_0$ and, under $\ARDone$,
$g^{\mu}_0$, $g^{v}_0$ (Section~\ref{sec:repair_laws}); the replacement values
$\mu^{\new}$, $v^{\new}$ (Section~\ref{sec:replacement}).

\emph{Indicator form} (\texttt{encoding = "indicator"}): the rows
Eqs.~\eqref{eq:a_ind_sum}--\eqref{eq:a_ind_anchor} with the same day maps,
Eqs.~\eqref{eq:g_map_mu}--\eqref{eq:g_map_v}.

\subsubsection{Reliability row}

Requires $\varepsilon < 0.5$ (Section~\ref{sec:consistency_checks}). On every day
$k = 1, \ldots, T$:
\begin{equation}
  \kappa_G^2\, v_k \leq (\tau - \mu_k)^2, \qquad \mu_k \leq \tau.
  \label{eq:g_row}
\end{equation}

\textbf{Forms.} \texttt{exact}: Eq.~\eqref{eq:g_row} as written, a nonconvex
quadratic constraint (\texttt{NonConvex} $= 2$, Section~\ref{sec:linear_forms}).
\texttt{tangent} and \texttt{pwl}: Section~\ref{sec:linear_forms}, with $\chi = v$,
$f(\mu) = (\tau - \mu)^2/\kappa_G^2$ and the side row $\mu \leq \tau$.

\textbf{Optional row.} If \texttt{v\_max\_user} is given for the cell:
$v_k \leq V^{\mathrm{user}}$ on every day.

\subsection{Inverse Gaussian Model}
\label{sec:dyn_ig}
% ----------------------------------------------------------------

For cells $(i,\ell)$ with \texttt{model} $=$ \texttt{inverse\_gaussian} (IG).

\textbf{Model.} $\mathrm{IG}(\mu, \lambda)$ is the inverse Gaussian law with mean
$\mu$ and shape $\lambda$. Every term of mean $a$ (a mission increment, mean
$\mu^{\inc}_{jk}$; the initial damage, $\mu_0$; a replacement draw, $\mu^{\new}$)
has the law $\mathrm{IG}(a, a/\eta) = a\,Z$, with $Z \sim \mathrm{IG}(1, 1/\eta)$
and $\eta > 0$ the squared coefficient of variation of the terms of the cell (input \texttt{eta}). A known damage is a
constant. No independence between terms is required (scoping document, section
``Stochastic orderings'').

\textbf{Laws and tracked quantities.} $\ARDinf$ and $\ARDone$. Tracked: $\mu_k$;
under $\ARDone$ also the anchor $g^{\mu}_k$. Day map:
\begin{equation}
  \mu_k = \begin{cases}
    \mu_{k-1} + \delta\mu_k & \text{no intervention on day } k,\\
    (1-\rho)\,\mu_{k-1} & \text{repair, } \ARDinf,\\
    (1-\rho)\,\mu_{k-1} + \rho\, g^{\mu}_{k-1} & \text{repair, } \ARDone,\\
    \mu^{\new} & \text{replacement,}
  \end{cases}
  \label{eq:ig_map}
\end{equation}
with $\delta\mu_k = \sum_{j=1}^{M} x_{ijk}\,\mu^{\inc}_{jk}$.

\textbf{Big-M rows} (\texttt{encoding = "bigm"}, the default; conditions in
Section~\ref{sec:dyn_gaussian}). Big-M constant: $\tau$ for $\mu$ and $g^{\mu}$.
\begin{align}
  &\text{no intervention:} & \mu_k &\geq \mu_{k-1} + \delta\mu_k - \tau\,(x^m_k + x^r_k),
    \label{eq:ig_mu_carry} \\
  &\text{repair, } \ARDinf\text{:} & \mu_k &\geq (1-\rho)\,\mu_{k-1} - \tau\,(1 - x^m_k),
    \label{eq:ig_mu_inf} \\
  &\text{repair, } \ARDone\text{:} & \mu_k &\geq (1-\rho)\,\mu_{k-1} + \rho\, g^{\mu}_{k-1}
    - \tau\,(1 - x^m_k),
    \label{eq:ig_mu_one} \\
  &\text{replacement:} & \mu_k &\geq \mu^{\new} - \tau\,(1 - x^r_k), \quad
    \mu_k \leq \mu^{\new} + \tau\,(1 - x^r_k).
    \label{eq:ig_mu_repl}
\end{align}

\emph{Anchor} ($\ARDone$):
\begin{align}
  g^{\mu}_k - \mu_k &\leq \tau\,(1 - e_k), & \mu_k - g^{\mu}_k &\leq \tau\,(1 - e_k),
    \label{eq:ig_anchor_set} \\
  g^{\mu}_k - g^{\mu}_{k-1} &\leq \tau\, e_k, & g^{\mu}_{k-1} - g^{\mu}_k &\leq \tau\, e_k.
    \label{eq:ig_anchor_keep}
\end{align}

\emph{Day 0 and replacement.} The constants $\mu_0$ and, under $\ARDone$, $g^{\mu}_0$
(Section~\ref{sec:repair_laws}); the replacement value $\mu^{\new}$
(Section~\ref{sec:replacement}).

\emph{Indicator form} (\texttt{encoding = "indicator"}): the rows
Eqs.~\eqref{eq:a_ind_sum}--\eqref{eq:a_ind_anchor} with the same day map,
Eq.~\eqref{eq:ig_map}.

\subsubsection{Reliability row}

Let $q$ be the $(1-\varepsilon)$-quantile of $Z$, $\Pr(Z > q) = \varepsilon$, and
$\bar q = \mathbb{E}[Z \mid Z > q]$. On every day $k = 1, \ldots, T$:
\begin{equation}
  \mu_k \leq \bar\mu, \qquad \bar\mu = \frac{\tau}{\bar q}.
  \label{eq:ig_row}
\end{equation}
The row is linear: it is built in its exact form, and a value of
\texttt{reliability\_impl} at the cell is ignored.

\textbf{Computation of $\bar\mu$} (offline, once per cell). With
$r(x) = 1/\sqrt{\eta x}$, the distribution function of $Z$ is
\[
  F(x) = \Phi\bigl(r(x)\,(x - 1)\bigr) + e^{2/\eta}\,\Phi\bigl(-r(x)\,(x + 1)\bigr).
\]
The second term is computed as $\exp\bigl(2/\eta + \ln\Phi(-r(x)(x+1))\bigr)$, with
$\ln\Phi$ from a log-space routine (\texttt{scipy.special.log\_ndtr}).
\begin{enumerate}[leftmargin=1.5em, nosep]
  \item $q$: the root of $1 - F(q) = \varepsilon$, by bisection or \texttt{brentq}
        on $\ln q$; equivalently, the method \texttt{isf} of
        \texttt{scipy.stats.invgauss} with \texttt{mu} $= \eta$, \texttt{scale}
        $= 1/\eta$.
  \item The tail mean: $\mathbb{E}[Z;\, Z > q] = F(1/q)$, so
        $\bar\mu = \tau\,\varepsilon/F(1/q)$. Quadrature of
        $\int_q^\infty z\, f_Z(z)\, dz$, with
        $f_Z(z) = (2\pi\eta z^3)^{-1/2}\exp\bigl(-(z-1)^2/(2\eta z)\bigr)$, gives
        the same value.
\end{enumerate}

% ----------------------------------------------------------------
\subsection{Wiener Model}
\label{sec:dyn_wiener}
% ----------------------------------------------------------------

For cells $(i,\ell)$ with \texttt{model} $=$ \texttt{wiener}.

\textbf{Model.} A mission day adds $\mathcal{N}(\mu^{\inc}_{jk}, \sigma^2)$, with
the mean from \texttt{mu} and one diffusion constant $\sigma > 0$ per cell (input
\texttt{sigma}); the initial damage is $\mathcal{N}(\mu_0, v_0)$, $v_0 \geq 0$; a
replacement draw is $\mathcal{N}(\mu^{\new}, v^{\new})$. \textbf{Assumption W1.} These
terms are mutually independent. A repair acts on the mean only; the variance falls
only at a replacement.

\textbf{Laws and tracked quantities.} $\ARDinf$ and $\ARDone$. Tracked: $\mu_k$ and
$v_k$; under $\ARDone$ also the mean anchor $g^{\mu}_k$ (no variance anchor). The
mean follows Eq.~\eqref{eq:g_map_mu}. The variance follows
\begin{equation}
  v_k = \begin{cases}
    v_{k-1} + \delta v_k & \text{no intervention on day } k,\\
    v_{k-1} & \text{repair, both laws},\\
    v^{\new} & \text{replacement,}
  \end{cases}
  \qquad \delta v_k = \sigma^2 \sum_{j=1}^{M} x_{ijk}.
  \label{eq:w_map_v}
\end{equation}

\textbf{Big-M rows} (\texttt{encoding = "bigm"}, the default; conditions in
Section~\ref{sec:dyn_gaussian}). Big-M constants: $\tau$ for $\mu$ and $g^{\mu}$;
$V_{\max} = \tau^2/\kappa_G^2$ for $v$, with $\kappa_G = \Phi^{-1}(1-\varepsilon)$.

\emph{Mean.}
\begin{align}
  &\text{no intervention:} & \mu_k &\geq \mu_{k-1} + \delta\mu_k - \tau\,(x^m_k + x^r_k),
    \label{eq:w_mu_carry} \\
  &\text{repair, } \ARDinf\text{:} & \mu_k &\geq (1-\rho)\,\mu_{k-1} - \tau\,(1 - x^m_k),
    \label{eq:w_mu_inf} \\
  &\text{repair, } \ARDone\text{:} & \mu_k &\geq (1-\rho)\,\mu_{k-1} + \rho\, g^{\mu}_{k-1}
    - \tau\,(1 - x^m_k),
    \label{eq:w_mu_one} \\
  &\text{replacement:} & \mu_k &\geq \mu^{\new} - \tau\,(1 - x^r_k), \quad
    \mu_k \leq \mu^{\new} + \tau\,(1 - x^r_k).
    \label{eq:w_mu_repl}
\end{align}

\emph{Variance} (both laws; no anchor).
\begin{align}
  &\text{no intervention, repair:} & v_k &\geq v_{k-1} + \delta v_k - V_{\max}\, x^r_k,
    \label{eq:w_vrow} \\
  &\text{replacement:} & v_k &\geq v^{\new} - V_{\max}\,(1 - x^r_k), \quad
    v_k \leq v^{\new} + V_{\max}\,(1 - x^r_k).
    \label{eq:w_v_repl}
\end{align}

\emph{Anchor} ($\ARDone$, mean only):
\begin{align}
  g^{\mu}_k - \mu_k &\leq \tau\,(1 - e_k), & \mu_k - g^{\mu}_k &\leq \tau\,(1 - e_k),
    \label{eq:w_anchor_set} \\
  g^{\mu}_k - g^{\mu}_{k-1} &\leq \tau\, e_k, & g^{\mu}_{k-1} - g^{\mu}_k &\leq \tau\, e_k.
    \label{eq:w_anchor_keep}
\end{align}

\emph{Day 0 and replacement.} The constants $\mu_0$, $v_0$ and, under $\ARDone$,
$g^{\mu}_0$ (Section~\ref{sec:repair_laws}); the replacement values $\mu^{\new}$,
$v^{\new}$ (Section~\ref{sec:replacement}).

\emph{Indicator form} (\texttt{encoding = "indicator"}): the rows
Eqs.~\eqref{eq:a_ind_sum}--\eqref{eq:a_ind_anchor} with the same day maps,
Eqs.~\eqref{eq:g_map_mu} and~\eqref{eq:w_map_v}: the variance has
$\psi = v_{k-1}$, and only $g^{\mu}$ has anchor rows.

\textbf{Reliability row.} The Gaussian row, Eq.~\eqref{eq:g_row}, with
$\kappa_G = \Phi^{-1}(1-\varepsilon)$, $\varepsilon < 0.5$,
$V_{\max} = \tau^2/\kappa_G^2$, on every day $k = 1, \ldots, T$, in the same forms
and with the same $f$ and side row (Section~\ref{sec:dyn_gaussian}). The optional
row $v_k \leq V^{\mathrm{user}}$ is added when \texttt{v\_max\_user} is given.

\emph{Note.} The loop row $v_T \leq v_{H_1}$ forces a replacement of the component
in the operating phase whenever its train flies a mission there; with
\texttt{allow\_replacement} false, the train cannot fly in the operating phase
(scoping document, section ``Stochastic orderings'', loop constraint for each
degradation model).

\subsection{Gamma Model}
\label{sec:dyn_gamma}
% ----------------------------------------------------------------

For cells $(i,\ell)$ with \texttt{model} $=$ \texttt{gamma}.

\textbf{Model.} $\mathrm{Gamma}(a, \beta)$ has shape $a$, rate $\beta$ and mean
$a/\beta$. Terms:
\begin{itemize}[leftmargin=1.5em, nosep]
  \item a mission increment with mean $\mu^{\inc}_{jk} > 0$ (\texttt{mu}) and rate
        $\beta_{jk}$ (\texttt{gamma\_beta}, \texttt{gamma\_beta\_trans}):
        $\mathrm{Gamma}(\beta_{jk}\mu^{\inc}_{jk},\, \beta_{jk})$;
  \item the initial damage, $\mu_0 > 0$: $\mathrm{Gamma}(\beta_0\mu_0,\, \beta_0)$
        when \texttt{gamma\_beta\_0} $= \beta_0$ is given; the known constant
        $\mu_0$ when it is omitted;
  \item a replacement draw, $\mu^{\new} > 0$:
        $\mathrm{Gamma}(\beta^{\new}\mu^{\new},\, \beta^{\new})$ when
        \texttt{gamma\_beta\_new} $= \beta^{\new}$ is given; the known constant
        $\mu^{\new}$ when it is omitted.
\end{itemize}
\textbf{Assumption G1.} All these terms are mutually independent.

\textbf{Laws and tracked quantities.} $\ARDinf$ and $\ARDone$. Tracked: $\mu_k$
(the shape is not tracked); under $\ARDone$ also the anchor $g^{\mu}_k$. Day map:
\begin{equation}
  \mu_k = \begin{cases}
    \mu_{k-1} + \delta\mu_k & \text{no intervention on day } k,\\
    (1-\rho)\,\mu_{k-1} & \text{repair, } \ARDinf,\\
    (1-\rho)\,\mu_{k-1} + \rho\, g^{\mu}_{k-1} & \text{repair, } \ARDone,\\
    \mu^{\new} & \text{replacement,}
  \end{cases}
  \label{eq:gm_map}
\end{equation}
with $\delta\mu_k = \sum_{j=1}^{M} x_{ijk}\,\mu^{\inc}_{jk}$.

\textbf{Big-M rows} (\texttt{encoding = "bigm"}, the default; conditions in
Section~\ref{sec:dyn_gaussian}). Big-M constant: $\tau$ for $\mu$ and $g^{\mu}$.
\begin{align}
  &\text{no intervention:} & \mu_k &\geq \mu_{k-1} + \delta\mu_k - \tau\,(x^m_k + x^r_k),
    \label{eq:gm_mu_carry} \\
  &\text{repair, } \ARDinf\text{:} & \mu_k &\geq (1-\rho)\,\mu_{k-1} - \tau\,(1 - x^m_k),
    \label{eq:gm_mu_inf} \\
  &\text{repair, } \ARDone\text{:} & \mu_k &\geq (1-\rho)\,\mu_{k-1} + \rho\, g^{\mu}_{k-1}
    - \tau\,(1 - x^m_k),
    \label{eq:gm_mu_one} \\
  &\text{replacement:} & \mu_k &\geq \mu^{\new} - \tau\,(1 - x^r_k), \quad
    \mu_k \leq \mu^{\new} + \tau\,(1 - x^r_k).
    \label{eq:gm_mu_repl}
\end{align}

\emph{Anchor} ($\ARDone$):
\begin{align}
  g^{\mu}_k - \mu_k &\leq \tau\,(1 - e_k), & \mu_k - g^{\mu}_k &\leq \tau\,(1 - e_k),
    \label{eq:gm_anchor_set} \\
  g^{\mu}_k - g^{\mu}_{k-1} &\leq \tau\, e_k, & g^{\mu}_{k-1} - g^{\mu}_k &\leq \tau\, e_k.
    \label{eq:gm_anchor_keep}
\end{align}

\emph{Day 0 and replacement.} The constants $\mu_0$ and, under $\ARDone$, $g^{\mu}_0$
(Section~\ref{sec:repair_laws}); the replacement value $\mu^{\new}$
(Section~\ref{sec:replacement}).

\emph{Indicator form} (\texttt{encoding = "indicator"}): the rows
Eqs.~\eqref{eq:a_ind_sum}--\eqref{eq:a_ind_anchor} with the same day map,
Eq.~\eqref{eq:gm_map}.

\textbf{Smallest rate.}
\begin{equation}
  \beta^* = \min\Bigl(\{\beta_{jk} : \mu^{\inc}_{jk} > 0\}
    \cup \{\beta_0 : \mu_0 > 0\} \cup \{\beta^{\new} : \mu^{\new} > 0\}\Bigr),
  \label{eq:gm_betastar}
\end{equation}
over the missions $j$ and the days $k$ of both phases. $\beta_0$ and $\beta^{\new}$
enter only when given, and $\beta^{\new}$ only when \texttt{allow\_replacement} is
true. A cell in which no term has a rate has the row $\mu_k \leq \tau$ in place of
Eq.~\eqref{eq:gm_row}.

\subsubsection{Reliability row}

$Q(a, x) = \Pr(\mathrm{Gamma}(a, 1) > x)$ is the regularised upper incomplete gamma
function (\texttt{gammaincc} of \texttt{scipy.special}). Let $t = \beta^*\tau$ and, for
$A \in [0, t)$,
\[
  w(A) = \max_{c \in (0, 1]} Q\!\left(\frac{A}{c},\, \frac{t}{c}\right).
\]
The sharp cap $A_1(t, \varepsilon)$ is the largest $A \in [0, t)$ with
$w(A) \leq \varepsilon$. For $\varepsilon \geq 1/2$ every $A < t$ satisfies this,
and $A_1$ is the value that step~3 below returns, which lies below $t$. On every
day $k = 1, \ldots, T$:
\begin{equation}
  \mu_k \leq \frac{A_1(\beta^*\tau,\, \varepsilon)}{\beta^*}.
  \label{eq:gm_row}
\end{equation}
The row is linear: it is built in its exact form, and a value of
\texttt{reliability\_impl} at the cell is ignored.

\textbf{Computation of $A_1$} (offline, once per cell):
\begin{enumerate}[leftmargin=1.5em, nosep]
  \item $\hat A$: the root of $Q(\hat A, t) = \varepsilon$, by bisection on
        $\hat A$ (\texttt{gammaincinv} solves for the second argument and does not
        apply).
  \item $w(A)$: maximum of $c \mapsto Q(A/c, t/c)$ over a logarithmic grid of at
        least 400 values of $c$ in $[\min(10^{-4}, t/100),\, 1]$, refined by a
        golden-section search between the neighbours of the best grid point. If
        the best grid point is the smallest $c$, the grid is extended downwards.
  \item If $\hat A < t$ and $w(\hat A) \leq \varepsilon$: $A_1 = \hat A$.
        Otherwise: bisection on $A$ in $[\varepsilon t,\, \min(\hat A, t))$, to a
        relative tolerance of $10^{-9}$; $w(\varepsilon t) \leq \varepsilon$ holds.
        The bisection returns the lower end of its last interval.
\end{enumerate}

% ----------------------------------------------------------------
\subsection{Rainflow Model}
\label{sec:dyn_rainflow}
% ----------------------------------------------------------------

For cells $(i,\ell)$ with \texttt{model} $=$ \texttt{rainflow}. The law of a
mission increment comes from rainflow counting of recorded load histories
(Palmgren--Miner damage) and enters only through summary statistics: mean,
variance, width of its range, or cumulant generating function (CGF) at a fixed
$s$. The tail bound is chosen per cell by \texttt{bound\_method}: \texttt{markov},
\texttt{cantelli}, \texttt{hoeffding}, \texttt{bernstein} or \texttt{chernoff}.

\textbf{Assumptions on the input data.}
\begin{itemize}[leftmargin=1.5em, nosep]
  \item \textbf{A0.} Every increment, the initial damage and every replacement draw
        are non-negative.
  \item \textbf{A1.} The mission increments, the initial damage and the replacement
        draws are mutually independent (all bounds except Markov).
  \item \textbf{A2} (Hoeffding, Bernstein). Each increment lies in an interval of
        width $b^{\inc}_{jk}$ (input \texttt{support}). The initial damage is a
        known part plus independent terms in intervals, with sum of squared widths
        $R_0$ (\texttt{R\_0}); the range of their sum has width $b^0$ (\texttt{support\_0}); a
        replacement draw likewise, with $R^{\new}$, $b^{\new}$ (\texttt{R\_new},
        \texttt{support\_new}). A known damage has $R = b = 0$, the defaults.
  \item \textbf{A3.} After day $T$ the operating phase repeats with period $H_2$
        (Section~\ref{sec:loop}).
\end{itemize}
The \emph{width} of $X$ is the width $b$ of an interval $[l, l + b]$ that contains
$X$ almost surely; it must satisfy $v \leq b^2/4$ (Section~\ref{sec:consistency_checks}).

\textbf{Tracked quantities per bound.} Every cell tracks $\mu$; the bound adds at
most one quantity; under $\ARDone$ each tracked quantity has an anchor ($g^{\mu}$
and $g^{v}$, $g^{R}$ or $g^{K}$). Both laws are accepted for every bound. ``Forms''
lists the forms in which the row is built (``all three'': \texttt{exact},
\texttt{tangent}, \texttt{pwl}); at a linear row a value of
\texttt{reliability\_impl} is ignored.

\begingroup\small
\begin{longtable}{@{}lllll@{}}
\toprule
\texttt{bound\_method} & Tracked & Increment inputs & Initial; replacement inputs & Forms \\
\midrule
\texttt{markov} & $\mu$ & \texttt{mu} & -- & \texttt{exact} \\
\texttt{cantelli} & $\mu$, $v$ & \texttt{mu}, \texttt{v}
  & \texttt{v\_0}; \texttt{replacement\_v} & all three \\
\texttt{hoeffding} & $\mu$, $R$ & \texttt{mu}, \texttt{support}
  & \texttt{R\_0}; \texttt{R\_new} & all three \\
\texttt{bernstein} & $\mu$, $v$ & \texttt{mu}, \texttt{v}, \texttt{support}
  & \texttt{v\_0}, \texttt{support\_0}; & all three \\
 & & & \texttt{replacement\_v}, \texttt{support\_new} & \\
\texttt{chernoff} & $\mu$, $K$ & \texttt{mu}, \texttt{cgf}, \texttt{s\_chernoff}
  & \texttt{cgf\_0}; \texttt{cgf\_new} & \texttt{exact} \\
\bottomrule
\end{longtable}
\endgroup

$R$ is the Hoeffding budget (sum of the squared widths of the terms of the damage).
$K$ is the CGF of the damage at $s = \texttt{s\_chernoff} > 0$. Day increments:
$\delta\mu_k = \sum_{j=1}^M x_{ijk}\,\mu^{\inc}_{jk}$,
$\delta v_k = \sum_{j} x_{ijk}\,v^{\inc}_{jk}$,
$\delta R_k = \sum_{j} x_{ijk}\,(b^{\inc}_{jk})^2$,
$\delta K_k = \sum_{j} x_{ijk}\,K^{\inc}_{jk}$, with
$K^{\inc}_{jk} = \ln\mathbb{E}\,e^{s X_{jk}}$ (input \texttt{cgf}).

\textbf{Day maps.} Each tracked quantity follows the generic map of
Section~\ref{sec:encoding} with its factor $a$: $1-\rho$ for $\mu$ and $K$,
$(1-\rho)^2$ for $v$ and $R$. It adds its day
increment on a day without intervention; a repair multiplies it by $a$ under
$\ARDinf$, and gives $a$ times its value plus $1-a$ times its anchor under
$\ARDone$; a replacement sets it to its replacement value. Its anchor is its value
just after the last intervention.

\textbf{Starting and replacement values.} $\mu$ and $v$: from the inputs
(Section~\ref{sec:replacement}). $R_0$ from \texttt{R\_0} and $R^{\new}$ from
\texttt{R\_new}, default 0. $K_0$ from \texttt{cgf\_0}, default $s\,\mu_0$;
$K^{\new}$ from \texttt{cgf\_new}, default $s\,\mu^{\new}$. With
\texttt{replacement\_as\_new}, all replacement values are 0. The defaults describe a
known damage; a random initial or replacement damage needs its own \texttt{R\_0},
\texttt{cgf\_0}, \texttt{R\_new}, \texttt{cgf\_new} (scoping document, section
``Conservative surrogates for the empirical damage-increment distribution'').

\textbf{Big-M rows} (\texttt{encoding = "bigm"}, the default; conditions in
Section~\ref{sec:dyn_gaussian}), with $\kappa = \ln(1/\varepsilon)$ and $c$ from
Eq.~\eqref{eq:rf_bsupport}. The rows of $\mu$ are built at every cell, the rows of
$v$ at Cantelli and Bernstein cells, the rows of $R$ at Hoeffding cells, and the rows
of $K$ at Chernoff cells. Big-M constants: $\tau$ for $\mu$ and $g^{\mu}$;
$M_v = V^{\mathrm{C}} = \varepsilon\tau^2/(1-\varepsilon)$ (Cantelli) or
$M_v = V^{\mathrm{B}} = \tau(\tau - 2c)/(2\kappa)$ (Bernstein) for $v$ and $g^{v}$;
$2\tau^2/\kappa$ for $R$ and $g^{R}$; $s\tau - \kappa$ for $K$ and $g^{K}$.

\emph{Mean} (every bound).
\begin{align}
  &\text{no intervention:} & \mu_k &\geq \mu_{k-1} + \delta\mu_k - \tau\,(x^m_k + x^r_k),
    \label{eq:rf_mu_carry} \\
  &\text{repair, } \ARDinf\text{:} & \mu_k &\geq (1-\rho)\,\mu_{k-1} - \tau\,(1 - x^m_k),
    \label{eq:rf_mu_inf} \\
  &\text{repair, } \ARDone\text{:} & \mu_k &\geq (1-\rho)\,\mu_{k-1} + \rho\, g^{\mu}_{k-1}
    - \tau\,(1 - x^m_k),
    \label{eq:rf_mu_one} \\
  &\text{replacement:} & \mu_k &\geq \mu^{\new} - \tau\,(1 - x^r_k), \quad
    \mu_k \leq \mu^{\new} + \tau\,(1 - x^r_k).
    \label{eq:rf_mu_repl}
\end{align}

\emph{Variance} (Cantelli, Bernstein).
\begin{align}
  &\text{no intervention:} & v_k &\geq v_{k-1} + \delta v_k - M_v\,(x^m_k + x^r_k),
    \label{eq:rf_v_carry} \\
  &\text{repair, } \ARDinf\text{:} & v_k &\geq (1-\rho)^2\, v_{k-1} - M_v\,(1 - x^m_k),
    \label{eq:rf_v_inf} \\
  &\text{repair, } \ARDone\text{:} & v_k &\geq (1-\rho)^2\, v_{k-1}
    + \bigl(1 - (1-\rho)^2\bigr)\, g^{v}_{k-1} - M_v\,(1 - x^m_k),
    \label{eq:rf_v_one} \\
  &\text{replacement:} & v_k &\geq v^{\new} - M_v\,(1 - x^r_k), \quad
    v_k \leq v^{\new} + M_v\,(1 - x^r_k).
    \label{eq:rf_v_repl}
\end{align}

\emph{Hoeffding budget} (Hoeffding).
\begin{align}
  &\text{no intervention:} & R_k &\geq R_{k-1} + \delta R_k
    - (2\tau^2/\kappa)\,(x^m_k + x^r_k),
    \label{eq:rf_R_carry} \\
  &\text{repair, } \ARDinf\text{:} & R_k &\geq (1-\rho)^2\, R_{k-1}
    - (2\tau^2/\kappa)\,(1 - x^m_k),
    \label{eq:rf_R_inf} \\
  &\text{repair, } \ARDone\text{:} & R_k &\geq (1-\rho)^2\, R_{k-1}
    + \bigl(1 - (1-\rho)^2\bigr)\, g^{R}_{k-1} - (2\tau^2/\kappa)\,(1 - x^m_k),
    \label{eq:rf_R_one} \\
  &\text{replacement:} & R_k &\geq R^{\new} - (2\tau^2/\kappa)\,(1 - x^r_k), \quad
    R_k \leq R^{\new} + (2\tau^2/\kappa)\,(1 - x^r_k).
    \label{eq:rf_R_repl}
\end{align}

\emph{Chernoff quantity} (Chernoff).
\begin{align}
  &\text{no intervention:} & K_k &\geq K_{k-1} + \delta K_k
    - (s\tau - \kappa)\,(x^m_k + x^r_k),
    \label{eq:rf_K_carry} \\
  &\text{repair, } \ARDinf\text{:} & K_k &\geq (1-\rho)\, K_{k-1}
    - (s\tau - \kappa)\,(1 - x^m_k),
    \label{eq:rf_K_inf} \\
  &\text{repair, } \ARDone\text{:} & K_k &\geq (1-\rho)\, K_{k-1} + \rho\, g^{K}_{k-1}
    - (s\tau - \kappa)\,(1 - x^m_k),
    \label{eq:rf_K_one} \\
  &\text{replacement:} & K_k &\geq K^{\new} - (s\tau - \kappa)\,(1 - x^r_k), \quad
    K_k \leq K^{\new} + (s\tau - \kappa)\,(1 - x^r_k).
    \label{eq:rf_K_repl}
\end{align}

\emph{Anchors} ($\ARDone$), for each pair
$(y, M_y) \in \{(\mu, \tau),\, (v, M_v),\, (R, 2\tau^2/\kappa),\, (K, s\tau - \kappa)\}$
whose quantity $y$ the cell tracks:
\begin{align}
  g^{y}_k - y_k &\leq M_y\,(1 - e_k), & y_k - g^{y}_k &\leq M_y\,(1 - e_k),
    \label{eq:rf_anchor_set} \\
  g^{y}_k - g^{y}_{k-1} &\leq M_y\, e_k, & g^{y}_{k-1} - g^{y}_k &\leq M_y\, e_k.
    \label{eq:rf_anchor_keep}
\end{align}

\emph{Day 0 and replacement.} For the quantities that the cell tracks: the constants
$\mu_0$, $v_0$, $R_0$, $K_0$ and, under $\ARDone$, $g^{\mu}_0$, $g^{v}_0$, $g^{R}_0$,
$g^{K}_0$ (Section~\ref{sec:repair_laws}); the replacement values $\mu^{\new}$,
$v^{\new}$, $R^{\new}$, $K^{\new}$ (paragraph ``Starting and replacement values'').

\emph{Indicator form} (\texttt{encoding = "indicator"}): the rows
Eqs.~\eqref{eq:a_ind_sum}--\eqref{eq:a_ind_anchor} with the same day maps (paragraph
``Day maps'').

\subsubsection{Reliability rows}

Each row holds on every day $k = 1, \ldots, T$.

\textbf{Markov} (\texttt{markov}):
\begin{equation}
  \mu_k \leq \varepsilon\,\tau.
  \label{eq:rf_markov}
\end{equation}

\textbf{Cantelli} (\texttt{cantelli}), with $\kappa_C = \sqrt{(1-\varepsilon)/\varepsilon}$:
\begin{equation}
  \kappa_C^2\, v_k \leq (\tau - \mu_k)^2, \qquad \mu_k \leq \tau.
  \label{eq:rf_cantelli}
\end{equation}

\textbf{Hoeffding} (\texttt{hoeffding}):
\begin{equation}
  (\tau - \mu_k)^2 \geq \frac{\kappa}{2}\, R_k, \qquad \mu_k \leq \tau.
  \label{eq:rf_hoeffding}
\end{equation}

\textbf{Bernstein} (\texttt{bernstein}). Support constant, precomputed per cell:
\begin{equation}
  b = \max\Bigl(b^0,\; b^{\new},\; \max_{j,k} b^{\inc}_{jk}\Bigr), \qquad
  c = \frac{\kappa\, b}{3},
  \label{eq:rf_bsupport}
\end{equation}
over the missions $j$ and the days $k$ of both phases; $b^{\new}$ enters only when
\texttt{allow\_replacement} is true. Row, with its side row:
\begin{equation}
  (\tau - c - \mu_k)^2 \geq c^2 + 2\kappa\, v_k, \qquad \mu_k \leq \tau - c.
  \label{eq:rf_bernstein}
\end{equation}
Requires $\tau > 2\kappa b/3$ (Section~\ref{sec:consistency_checks}).

\textbf{Chernoff} (\texttt{chernoff}), with $s = \texttt{s\_chernoff}$:
\begin{equation}
  K_k - s\,\tau \leq \ln\varepsilon.
  \label{eq:rf_chernoff}
\end{equation}
Requires $s > \kappa/\tau$ and $K^{\new} \leq s\tau - \kappa$
(Section~\ref{sec:consistency_checks}).

\textbf{Forms.} Markov and Chernoff rows are linear and built in their exact form.
The Cantelli, Hoeffding and Bernstein rows take the forms of
Section~\ref{sec:linear_forms} with:

\begingroup\small
\begin{longtable}{@{}lllll@{}}
\toprule
Bound & $\chi$ & $f(\mu)$ & Side row & $f(0)$ \\
\midrule
Cantelli & $v$ & $\varepsilon(\tau - \mu)^2/(1 - \varepsilon)$ & $\mu \leq \tau$
  & $\varepsilon\tau^2/(1-\varepsilon)$ \\
Hoeffding & $R$ & $2(\tau - \mu)^2/\kappa$ & $\mu \leq \tau$ & $2\tau^2/\kappa$ \\
Bernstein & $v$ & $\bigl((\tau - \mu)^2 - 2c(\tau - \mu)\bigr)/(2\kappa)$
  & $\mu \leq \tau - c$ & $\tau(\tau - 2c)/(2\kappa)$ \\
\bottomrule
\end{longtable}
\endgroup

At a Bernstein cell with $b > 0$ the tangent point must satisfy
$\mu_r < \sqrt{\tau(\tau - 2c)}$, and the \texttt{pwl} form requires
$\tau/(2P) < \sqrt{\tau(\tau - 2c)}$, $P = \texttt{pwl\_points}$
(Section~\ref{sec:consistency_checks}).

\textbf{Optional row.} If \texttt{v\_max\_user} is given for a Cantelli or
Bernstein cell: $v_k \leq V^{\mathrm{user}}$ on every day.

% ----------------------------------------------------------------
\subsection{Repair Cost Variable}
\label{sec:repair_cost}
% ----------------------------------------------------------------

$z_{i\ell k} \geq 0$ is the mean degradation removed by a repair of cell $(i,\ell)$ on
day $k$, for every model and both laws. It is built at cells with
$C_{R,i\ell} > 0$, on every day $k = 1, \ldots, T$ except the transitory days in the
mode \texttt{operating\_average}. Only the lower rows are built:
\begin{equation}
  z_{i\ell k} \;\geq\; \rho_{i\ell}\,\bigl(\mu_{i\ell,k-1} - g^{\mu}_{i\ell,k-1}\bigr)
    - \rho_{i\ell}\,\tau_{i\ell}\,\bigl(1 - x^m_{i\ell k}\bigr),
  \qquad z_{i\ell k} \geq 0,
  \label{eq:a_z}
\end{equation}
with $g^{\mu} \equiv 0$ under $\ARDinf$. At the optimum $z_{i\ell k} = 0$ on every day
without a repair, replacement days included. $z$ is an upper bound on the expected
removed degradation, except at the first repair when the starting anchor is above the
true one (scoping document, section ``Cost function'').

% ----------------------------------------------------------------
\subsection{Damage Penalty}
\label{sec:damage_reg}
% ----------------------------------------------------------------

The scalar $u \geq 0$ and its rows are built only when $C_D > 0$; with $C_D = 0$ the
input \texttt{penalty\_type} only selects the formula of the reported value $u$
(Section~\ref{sec:output}). One row per train and day:
\begin{align}
  \texttt{inf\_norm} \text{ (default)}:&\quad
    u \;\geq\; \sum_{\ell=1}^{L} \mu_{i\ell k} \qquad \forall\, i, k,
    \label{eq:a_u_inf} \\
  \texttt{quadratic}:&\quad
    u \;\geq\; \sum_{\ell=1}^{L} \mu_{i\ell k}^2 \qquad \forall\, i, k.
    \label{eq:a_u_quad}
\end{align}
At the optimum $u = \max_{i,k} \sum_{\ell} \mu_{i\ell k}$ (\texttt{inf\_norm}) or
$u = \max_{i,k} \sum_{\ell} \mu_{i\ell k}^2$ (\texttt{quadratic}): the largest damage of
one train on one day. Eq.~\eqref{eq:a_u_quad} is a rotated second-order cone; it does
not need \texttt{NonConvex}. If $C_D > 0$ and \texttt{penalty\_type = "quadratic"}, every cell
with a quadratic reliability row must have \texttt{reliability\_impl = "exact"};
otherwise a \texttt{ValueError} is raised (Section~\ref{sec:consistency_checks}). At a
cell with a linear row the value is ignored. With $C_D = 0$ the rule does not apply.

% ----------------------------------------------------------------
\subsection{Loop Constraint}
\label{sec:loop}
% ----------------------------------------------------------------

One hard row per cell and per coordinate $s$ of its tracked state:
\begin{equation}
  s_{i\ell T} \;\leq\; s_{i\ell H_1}.
  \label{eq:a_loop}
\end{equation}
The rows cover every tracked quantity of the cell (the mean, and the variance, $R$ or
$K$ where tracked) and, under $\ARDone$, every anchor. Each coordinate has its own
row; no row compares a scalar function of them, such as a failure-probability bound.
There is no soft loop penalty. With these rows every day of every repetition of the
operating phase satisfies the reliability requirement, for every model, both laws,
both encodings, every form, and any $H_1$, $H_2$ (scoping document, section
``Stochastic loop constraint'').

\emph{Consequences.} An $\ARDone$ cell with $\rho_{i\ell} < 1$ whose train flies, in the
operating phase, a mission with a positive mean increment for the cell must be
replaced at least once in that phase; with \texttt{allow\_replacement = false} its
train cannot fly such a mission there, and the model is infeasible if the fleet
cannot cover the missions otherwise (scoping document, section ``Stochastic loop
constraint''). A Wiener cell likewise needs a replacement in the operating phase
when its train flies a mission there (Section~\ref{sec:dyn_wiener}).

\section{Full Optimization Problem}
\label{sec:full_problem}
% ================================================================

This section collects the whole problem in one place. Each row is stated once, in the
section that the reference names; this section does not repeat the rows.

\textbf{Objective.} Minimise Eq.~\eqref{eq:a_objective}, the mode chosen by
\texttt{objective\_mode}, with the day cost Eq.~\eqref{eq:a_daycost}.

\textbf{Fleet rows.} For every train $i$ and day $k$: one activity,
Eq.~\eqref{eq:a_one_activity}. For every mission $j \geq 1$ and day $k$: coverage,
Eq.~\eqref{eq:a_coverage}. For every cell and day: depot-day compatibility,
Eq.~\eqref{eq:a_depot}.

\textbf{Rows of a cell.} For every cell $(i,\ell)$, with the model, repair law,
tail bound, encoding and reliability form of the cell:
\begin{enumerate}[nosep,leftmargin=2em]
  \item for every tracked quantity of the table below: the big-M rows of its model
        section (Sections~\ref{sec:dyn_gaussian}--\ref{sec:dyn_rainflow};
        \texttt{encoding = "bigm"}) or the indicator rows
        Eqs.~\eqref{eq:a_ind_sum}--\eqref{eq:a_ind_state} (\texttt{encoding = "indicator"});
  \item under $\ARDone$, for every tracked quantity except the Wiener variance: the
        anchor rows of its model section, or Eq.~\eqref{eq:a_ind_anchor};
  \item the reliability row of the table, on every day $k = 1, \ldots, T$, in the form
        \texttt{exact}, \texttt{tangent} (Eq.~\eqref{eq:a_tangent}) or \texttt{pwl}
        (Eqs.~\eqref{eq:a_pwl_sum}--\eqref{eq:a_pwl_cap}) for a quadratic row, and in
        its exact form for a linear row;
  \item where \texttt{v\_max\_user} is given (G, W, RF with Ca or Be): the optional row
        $v_{i\ell k} \leq V^{\mathrm{user}}_{\max,i\ell}$ of its model section, on every day;
  \item the loop rows Eq.~\eqref{eq:a_loop}, one per tracked quantity and per anchor;
  \item where $C_{R,i\ell} > 0$: the repair-cost rows Eq.~\eqref{eq:a_z}.
\end{enumerate}

\textbf{Damage penalty.} Where $C_D > 0$: Eq.~\eqref{eq:a_u_inf}
(\texttt{inf\_norm}) or Eq.~\eqref{eq:a_u_quad} (\texttt{quadratic}), for every train
and day.

\textbf{Domains.} The variables and their domains are those of
Section~\ref{sec:variables}; a variable that no row uses is not built.

The table gives, for each kind of cell, the tracked quantities with their repair
factor $a$ (Eq.~\eqref{eq:a_psi}), their natural ranges $M_s$
(Section~\ref{sec:encoding}) and the reliability row.

\textbf{Problem class.} The problem is a mixed-integer linear program when every

\subsection{Rules for the Values}

\begin{itemize}[nosep,leftmargin=1.5em]
  \item \textbf{No solution}: if Gurobi found no solution, the solution arrays and the cost report are \texttt{null}, and so are \texttt{objective} and \texttt{mip\_gap}.
  \item \textbf{A solution found}: the arrays hold the best solution, and \texttt{status} tells how the solve ended.
  \item \textbf{Upper bounds}: the arrays \texttt{mu}, \texttt{v}, \texttt{R}, \texttt{K}, \texttt{g\_mu}, \texttt{g\_v}, \texttt{g\_R}, \texttt{g\_K} and \texttt{z} hold the tracked variables of the model, and are upper bounds (Section~\ref{sec:encoding}).
  \item \textbf{$z$ on transitory days}: in the mode \texttt{operating\_average}, $z$ is not built on the days of the transitory phase (Section~\ref{sec:repair_cost}). At a cell with $C_{R,i\ell} > 0$ the result holds, for those days, the value computed after the solve:
  \begin{equation}\label{eq:c_zpost}
    z_{i\ell k} = \begin{cases}
      \rho_{i\ell}\,\bigl(\mu_{i\ell,k-1} - g^{\mu}_{i\ell,k-1}\bigr) & \text{if } x^m_{i\ell k} = 1,\\
      0 & \text{otherwise,}
    \end{cases}
    \qquad k = 1, \ldots, H_1,
  \end{equation}
  with $\mu_{i\ell 0} = \mu_{0,i\ell}$, $g^{\mu}_{i\ell 0}$ the starting anchor, and $g^{\mu} \equiv 0$ under \texttt{ardinf}.
  \item \textbf{Value of $u$}: it is recomputed from \texttt{mu}, and reported also when $C_D = 0$:
  \begin{equation}\label{eq:c_u}
    u = \max_{i,k} \sum_{\ell=1}^{L} \mu_{i\ell k} \quad (\texttt{inf\_norm}),
    \qquad
    u = \max_{i,k} \sum_{\ell=1}^{L} \mu_{i\ell k}^2 \quad (\texttt{quadratic}).
  \end{equation}
  \item \textbf{Costs}: the cost $c_k$ of day $k$ and the phase costs $J_{\mathrm{init}}$, $J_{\mathrm{op}}$ are Equations~\eqref{eq:a_daycost} and~\eqref{eq:a_phases} (Section~\ref{sec:objective}) on the arrays of the result, with $z_{i\ell k} = 0$ where it is \texttt{NaN}.
  \item \textbf{Objective}: if the variable $u$ has no slack, \texttt{objective} equals, up to the tolerance of the solver, the key below for the mode in use; otherwise it is larger by $C_D$ times the slack.
  \begin{itemize}[nosep,leftmargin=1.5em]
    \item mode \texttt{total}: \texttt{J\_total};
    \item mode \texttt{operating\_average}: \texttt{operating\_objective};
    \item mode \texttt{evaluation\_total}: \texttt{evaluation\_objective}.
  \end{itemize}
\end{itemize}

\section{Horizon Sweeps}
\label{sec:sweeps}
% ================================================================

A horizon sweep solves one input for several pairs $(H_1, H_2)$ and ranks the cases. \texttt{sweep\_operating\_horizons} varies $H_2$ for one $H_1$; \texttt{sweep\_horizon\_grid} varies $H_1$ and $H_2$.
No input key starts a sweep, and \texttt{solve()} never runs one.

\subsection{Cost Measures and Ranking}
\label{sec:sweep_criteria}

$J_{\mathrm{init}}$ and $J_{\mathrm{op}}$ of a case are Eq.~\eqref{eq:a_phases} on its solution. The cost per operating day, and the projected cost over an evaluation horizon $E > H_1$, are
\begin{equation}
  \bar J_{\mathrm{op}} = J_{\mathrm{op}} / H_2, \qquad
  P_E = J_{\mathrm{init}} + (E - H_1)\,\bar J_{\mathrm{op}} .
  \label{eq:d_projected}
\end{equation}
\begin{itemize}[nosep,leftmargin=1.5em]
  \item \textbf{Feasible case}: its result holds a solution and its status is not \texttt{"infeasible"}, \texttt{"unbounded"} or \texttt{"inf\_or\_unbounded"}.
  \item \textbf{Proven case}: it is feasible and its status is \texttt{"optimal"} at the MIP gap used for the case. This gap is Gurobi's \texttt{MIPGap} after all options are set, \texttt{gurobi\_params} included (Section~\ref{sec:run_options}). It is the entry \texttt{requested\_mip\_gap} of \texttt{performance}.
  \item \textbf{Ranking value}: $\bar J_{\mathrm{op}}$ in \texttt{sweep\_operating\_horizons}. In \texttt{sweep\_horizon\_grid} it is $P_E$ if an evaluation horizon is given, otherwise $\bar J_{\mathrm{op}}$.
  \item \textbf{Best proven case}: the proven case with the smallest ranking value.
  \item \textbf{Best feasible case}: the feasible case with the smallest ranking value.
  \item \textbf{Tie rule}: a tie goes to the smaller $H_2$; in the grid, to the smaller $H_1$, then the smaller $H_2$.
\end{itemize}

\typerow{\texttt{gradient\_tolerance}}{\texttt{1e-3}}{Early stop (Section~\ref{sec:sweep_stop}); finite and $\ge 0$}
\typerow{\texttt{flat\_gradients\_required}}{\texttt{2}}{Early stop (Section~\ref{sec:sweep_stop}); $\ge 1$}
\typerow{\texttt{minimum\_cases}}{\texttt{3}}{Early stop (Section~\ref{sec:sweep_stop}); $\ge 2$}
\typerow{\texttt{maximum\_mip\_gap\_for\_stopping}}{\texttt{None}}{Early stop (Section~\ref{sec:sweep_stop}); \texttt{None} or a finite number $\ge 0$}
\typerow{\texttt{warm\_start}}{\texttt{False}}{Warm start from the preceding case (Section~\ref{sec:warm_sweeps})}
\typerow{\texttt{warm\_start\_mode}}{\texttt{"start"}}{Mode of that warm start (Section~\ref{sec:warm_sweeps})}
\typerow{\texttt{n\_workers}}{\texttt{1}}{Number of cases solved at the same time (Section~\ref{sec:sweep_parallel})}
\typerow{\texttt{objective\_mode}}{\texttt{"operating\_average"}}{Written into every case input; \texttt{"evaluation\_total"} needs $E > H_1$}
\typerow{\texttt{evaluation\_horizon}}{\texttt{None}}{Written into every case input; \texttt{"evaluation\_total"} needs $E > H_1$}
\tabend

\blockhead{Steps}
\begin{enumerate}[nosep,label=\arabic*.]
  \item Read the input file with the input reader (Section~\ref{sec:schema}). The data must be a mapping.
  \item Check every argument.
  \item For each $H_2$, the case input is the input data with \texttt{H} $= [H_1, H_2]$, and with \texttt{objective\_mode} and \texttt{evaluation\_horizon} (if given) replaced. Time-indexed data are not interpolated: a profile whose length is not $H_2$ fails the checks of Section~\ref{sec:consistency_checks}, as an error of that case.
  \item Solve the case input with \texttt{solve\_mapping} (Section~\ref{sec:data_flow}) and \texttt{results\_path=None}; no temporary file is written. Keep the row of the case, not its schedule.
  \item After each case: append its row, annotate the gradient (Section~\ref{sec:sweep_stop}), test the stop rule, write a checkpoint if \texttt{output\_path} is given.
  \item At the end, write the final report and return it.
\end{enumerate}

\blockhead{Errors}
\tabstart{p{3.4cm}p{11.6cm}}{Exception & Raised when}
\rejrow{\texttt{TypeError}}{the data of the input file are not a mapping}
\rejrow{\texttt{ValueError}}{before the first case: an invalid argument; a list \texttt{H} whose length is not two; \texttt{warm\_start} or \texttt{stop\_on\_gradient} with $\texttt{n\_workers} > 1$. Such an error is never recorded as a case error}
\rejrow{none (captured)}{an error inside a case; it is captured in the row of the case (Section~\ref{sec:sweep_report})}
\tabend

\subsection{Early Stop}
\label{sec:sweep_stop}

Let $\bar J_n$ be the cost per operating day of the $n$-th evaluated case. If cases $n-1$ and $n$ are feasible, the relative gradient is
\begin{equation}
  \hat g_n = \frac{\bar J_n - \bar J_{n-1}}{(H_{2,n} - H_{2,n-1})\,\max\{\,|\bar J_{n-1}|,\ \varepsilon_{\mathrm{mach}}\}},
  \label{eq:d_gradient}
\end{equation}
with $\varepsilon_{\mathrm{mach}}$ the machine precision of double-precision numbers.

\blockhead{Class of a case}
With $t = \texttt{gradient\_tolerance}$, the class of case $n$ is:
\tabstart{p{3.4cm}p{11.6cm}}{Class & Condition}
\rejrow{\texttt{"increase"}}{$\hat g_n > t$}
\rejrow{\texttt{"decrease"}}{$\hat g_n < -t$}
\rejrow{\texttt{"flat"}}{otherwise: $-t \le \hat g_n \le t$}
\rejrow{\texttt{"unavailable"}}{$n = 1$, or one of the two cases is not feasible}
\tabend

\blockhead{Definitions}
\begin{itemize}[nosep,leftmargin=1.5em]
  \item \textbf{Qualifies}: a case qualifies if it reports a finite MIP gap at most its threshold. The threshold is \texttt{maximum\_mip\_gap\_for\_stopping} if it is a number, otherwise the MIP gap used for the case (\texttt{requested\_mip\_gap} of its row).
  \item \textbf{Eligible to stop}: the gradient of case $n$ is eligible to stop if cases $n-1$ and $n$ qualify.
  \item \textbf{Annotation}: every row carries its gradient, class and eligibility, also if \texttt{stop\_on\_gradient} is false.
\end{itemize}

\blockhead{Stop rule}
With \texttt{stop\_on\_gradient=True} the sweep stops after case $n$ if all of these hold:
\begin{enumerate}[nosep,label=\arabic*.]
  \item $n \ge \texttt{minimum\_cases}$.
  \item The gradient of case $n$ is eligible to stop.
  \item One of the two reasons holds:
    \begin{itemize}[nosep]
      \item reason \texttt{"cost\_increase"}: the class of case $n$ is \texttt{"increase"};
      \item reason \texttt{"flat\_gradient"}: the last \texttt{flat\_gradients\_required} cases up to $n$ all have the class \texttt{"flat"} and an eligible gradient.
    \end{itemize}
\end{enumerate}
The last candidate of \texttt{operating\_horizons} is a hard limit.

\subsection{Parallel Cases}
\label{sec:sweep_parallel}

\begin{itemize}[nosep,leftmargin=1.5em]
  \item With $\texttt{n\_workers} > 1$, up to \texttt{n\_workers} cases are solved at the same time, each in its own process with its own Gurobi environment and one Gurobi licence token.
  \item The option is refused with \texttt{warm\_start} and with \texttt{stop\_on\_gradient}.
  \item Rows arrive in the order of completion. The report orders them by $H_2$, and each rewrite recomputes the gradient annotations over the ordered rows.
\end{itemize}

\section{Warm Starts}
\label{sec:warm_starts}
% ================================================================

A warm start gives Gurobi values for the binary variables. Four mechanisms exist:

\tabstart{p{3.4cm}p{11.6cm}}{Mechanism & Attribute and source}
\rejrow{Start}{attribute \texttt{Start}, from a source, with an optional completion (Section~\ref{sec:warm_start_modes})}
\rejrow{Hints}{attribute \texttt{VarHintVal}, from a source (Section~\ref{sec:warm_start_modes})}
\rejrow{Relaxation start}{see Section~\ref{sec:warm_relaxation}}
\rejrow{Greedy heuristic}{builds a source from the input (Section~\ref{sec:greedy})}
\tabend

\subsection{Interface and Reports}
\label{sec:warm_interface}
\label{sec:warm_reports}

\begin{itemize}[nosep,leftmargin=1.5em]
  \item \textbf{\texttt{warm\_start}}: an argument of \texttt{solve()}; a source or \texttt{None} (default).
  \item \textbf{\texttt{warm\_start\_mode}}: an argument of \texttt{solve()}; \texttt{"start"} (default), \texttt{"hint"} or \texttt{"both"}. Another value raises \texttt{ValueError}.
  \item \textbf{Source}: a result dictionary or the dictionary returned by the greedy heuristic (Section~\ref{sec:greedy}).
  \item \textbf{Keys of a source}: it carries \texttt{x} (shape $F' \times (M'+1) \times T'$) and the integers \texttt{H1}, \texttt{H2} with $T' = H_1' + H_2'$. It may carry \texttt{m} and \texttt{r} (shape $F' \times L' \times T'$).
  \item \textbf{Source without \texttt{x}}: a source whose \texttt{x} is missing or \texttt{null} has no effect.
  \item \textbf{Other dimensions}: $F'$, $M'$, $L'$ may differ from $F$, $M$, $L$. Values are set for the indices that both have.
  \item \textbf{Reports}: the result keys \texttt{warm\_start} and \texttt{relaxation\_warm\_start} report what each mechanism did (Section~\ref{sec:output_reports}).
\end{itemize}

\subsection{Day Mapping}
\label{sec:warm_map}

Day $k \in \{1,\ldots,T\}$ takes the values of the source day
\begin{equation}
  \sigma(k) =
  \begin{cases}
    k, & k \leq \min\{H_1, H_1'\}, \\
    H_1' + 1 + \bigl(\max\{0,\ k - H_1 - 1\} \bmod H_2'\bigr), & \text{otherwise.}
  \end{cases}
  \label{eq:d_daymap}
\end{equation}
The mapped values, rounded to the nearest integer, are:
\tabstart{p{4.4cm}p{10.6cm}}{Variable & Value from the source}
\rejrow{$x_{ijk}$ for $j = 0,\ldots,M$}{$x'_{ij\sigma(k)}$}
\rejrow{$x^m_{i\ell k}$}{$m'_{i\ell\sigma(k)}$, or $0$ if the source has no \texttt{m}}
\rejrow{$x^r_{i\ell k}$}{$r'_{i\ell\sigma(k)}$, if \texttt{allow\_replacement} is true and the source has \texttt{r}}
\tabend
A binary variable that these values fix through its defining rows (the selector $n_{i\ell k}$ of Eq.~\eqref{eq:a_ind_sum}) gets that value.

\subsection{Start, Hints and Completion}
\label{sec:warm_start_modes}

\tabstart{p{3.4cm}p{11.6cm}}{Mode & Effect}
\rejrow{\texttt{"start"}}{sets \texttt{Start} of every mapped variable; continuous variables get no value. The completion runs if the source requests it}
\rejrow{\texttt{"hint"}}{sets \texttt{VarHintVal} instead, with no \texttt{Start}, no completion and no \texttt{VarHintPri}}
\rejrow{\texttt{"both"}}{sets \texttt{Start} and \texttt{VarHintVal}. The completion runs if the source requests it}
\tabend

\blockhead{Completion}
\begin{itemize}[nosep,leftmargin=1.5em]
  \item \textbf{Request}: only the source requests it, with \texttt{complete\_binary\_start = true}; the greedy heuristic does.
  \item \textbf{Condition}: it runs if the mapping set at least one value.
  \item \textbf{Time limit}: \texttt{completion\_time\_limit} of the source (seconds, default $60$).
\end{itemize}
\begin{enumerate}[nosep,label=\arabic*.]
  \item Copy the model; fix every binary variable that has a \texttt{Start} value to that value; the other binary variables stay free. Optimise the copy within the time limit.
  \item If the copy has a solution, set \texttt{Start} of every variable of the original model to its value in the copy.
  \item Otherwise record the status of the copy. If it is infeasible, compute an irreducible infeasible subset (IIS, Gurobi \texttt{computeIIS}) of the copy and record the names of at most $50$ of its linear rows and general constraints.
\end{enumerate}
The original model is not changed; a failed completion does not stop the solve.

\subsection{Relaxation Start}
\label{sec:warm_relaxation}

\blockhead{Condition}
\begin{itemize}[nosep,leftmargin=1.5em]
  \item The run option \texttt{relaxation\_warm\_start} (Section~\ref{sec:run_options}) is true.
  \item No start or hint was applied (\texttt{applied} is false in the report \texttt{warm\_start}).
\end{itemize}

\blockhead{Steps}
\begin{enumerate}[nosep,label=\arabic*.]
  \item Copy the model and relax its linear rows with Gurobi's \texttt{feasRelaxS} (sum of absolute violations); integrality, variable bounds and general constraints are kept.
  \item Optimise the copy with the time limit $\max\{1,\ \texttt{relaxation\_time\_limit}\}$ seconds and the MIP gap $0.05$.
  \item If the copy has a solution, set \texttt{Start} of every integer variable of the original model to the rounded value of the variable of the same name in the copy.
\end{enumerate}
The relaxed solution need not be feasible for the original model.

\subsection{Warm Starts in Sweeps}
\label{sec:warm_sweeps}

\begin{itemize}[nosep,leftmargin=1.5em]
  \item With \texttt{warm\_start=True}, the source of a case is the result of the nearest preceding case of the same $H_1$ that has a solution, used in the mode \texttt{warm\_start\_mode}.
  \item The first case of each $H_1$ has no source.
  \item A case with an error or without a solution is never a source.
\end{itemize}

\subsection{Greedy Heuristic}
\label{sec:greedy}

\end{lstlisting}

\blockhead{Arguments}
\tabstart{p{4.3cm}p{2.3cm}p{8.2cm}}{Argument & Default & Rule}

\typerow{\texttt{repair\_trigger}}{\texttt{0.70}}{$r = \texttt{repair\_trigger}$ must lie in $[0,1]$}

\blockhead{Errors}
\tabstart{p{3.4cm}p{11.6cm}}{Exception & Raised when}
\rejrow{\texttt{ValueError}}{$r = \texttt{repair\_trigger}$ does not lie in $[0,1]$}
\tabend

\blockhead{Keys of the returned source}
\tabstart{p{5.2cm}p{9.8cm}}{Key & Content}
\rejrow{\texttt{H1}, \texttt{H2}, \texttt{x}, \texttt{m}, \texttt{r}}{as in a source (Section~\ref{sec:warm_interface})}
\rejrow{\texttt{complete\_binary\_start}}{\texttt{true}}
\rejrow{\texttt{completion\_time\_limit}}{$60$}
\tabend

\blockhead{Steps of the construction pass}
A proxy state $\hat s_{i\ell}$ starts at $\mu_{0,i\ell}$. For each day $k = 1,\ldots,T$:
\begin{enumerate}[nosep,label=\arabic*.]
  \item Order the missions by decreasing $\max_{i,\ell} \mu^{\inc}_{i\ell jk}/\tau_{i\ell}$; a tie goes to the larger $j$.
  \item In this order, give each mission to the train $i$ without a mission on day $k$ that minimises, in lexicographic order,
    $\bigl(\max_\ell (\hat s_{i\ell} + \mu^{\inc}_{i\ell jk})/\tau_{i\ell},\ \sum_\ell (\hat s_{i\ell} + \mu^{\inc}_{i\ell jk})/\tau_{i\ell}\bigr)$; a tie goes to the smaller $i$.
    Add $\mu^{\inc}_{i\ell jk}$ to $\hat s_{i\ell}$. The check $F > M$ (Section~\ref{sec:consistency_checks}) guarantees a train for every mission.
  \item A train without a mission is idle, unless some component has $\hat s_{i\ell} > r\,\tau_{i\ell}$: then $x_{i0k} = 1$, and every such component is repaired ($x^m_{i\ell k} = 1$, $\hat s_{i\ell} \leftarrow (1-\rho_{i\ell})\,\hat s_{i\ell}$ for every repair law).
\end{enumerate}
The construction pass schedules no replacement.

\blockhead{Steps of the loop pass}
For each cell:
\begin{enumerate}[nosep,label=\arabic*.]
  \item Compute the reference trajectory $\zeta$ (Section~\ref{sec:encoding}) of the current schedule from the initial values, starting anchors and replacement values of the inputs.
  \item Compute the excess $e$ of the cell: the largest of
    \begin{itemize}[nosep]
      \item the loop excesses $\max\{0,\ \zeta^{q}_{T} - \zeta^{q}_{H_1}\}/M_q$ of every tracked quantity and anchor $q$ with natural range $M_q$ (Section~\ref{sec:loop});
      \item the violations of the reliability row on every day, divided by the natural range of the bounded quantity.
    \end{itemize}
    The row is taken in the form built at the cell (Sections~\ref{sec:dyn_gaussian}--\ref{sec:dyn_rainflow}): the exact row for \texttt{"exact"}, the tangent row for \texttt{"tangent"}, and for \texttt{"pwl"} the cap of the segment that contains the mean of the day (Section~\ref{sec:linear_forms}).
  \item While $e > 10^{-10}$: for every free day $k \in \{H_1+1,\ldots,T\}$ (the train has no mission, the cell no intervention), put a repair of the cell on day $k$ (the train goes to the depot) and recompute $e$; keep the repair with the smallest $e$, a tie to the later day.
  \item If no repair lowers $e$ by more than $10^{-10}$ and replacement is allowed, repeat the trial with a replacement.
  \item If no trial lowers $e$, count one failure for the cell and go to the next cell.
\end{enumerate}
A start with failures is returned.

\blockhead{Report keys}
\texttt{GreedyWarmStartReport.as\_dict()} returns plain Python types.
\tabstart{p{5.2cm}p{9.8cm}}{Key & Content}
\rejrow{\texttt{repairs}}{the number of ones in \texttt{m}}
\rejrow{\texttt{replacements}}{the number of ones in \texttt{r}}
\rejrow{\texttt{repeatability\_feasible}}{true without a failure}
\rejrow{\texttt{repeatability\_failures}}{the number of cells with a failure}
\rejrow{\texttt{maximum\_repeatability\_excess}}{the largest raw excess over all cells after the loop pass}
\rejrow{\texttt{maximum\_proxy\_ratio}}{the largest $\hat s_{i\ell}/\tau_{i\ell}$ of the construction pass and reference mean over $\tau_{i\ell}$ of the loop pass}
\rejrow{\texttt{assignment\_order}}{for each day, the missions in the order treated}
\tabend

\subsubsection{Exact validator}

Module \texttt{gamma\_utils.gamma\_tail\_validator}, not exported.

\begin{lstlisting}[language=Python]
validate_gamma_tail_bound_schedule(cfg, result, *, tolerance=1e-8,
    convolution_tolerance=1e-12, max_series_terms=100000,
    include_steps=False, raise_on_failure=False) -> dict
validate_gamma_tail_bound_files(input_path, result_path, report_path=None,
                                **kwargs) -> dict
\end{lstlisting}

\blockhead{Further arguments}
\tabstart{p{4.3cm}p{2.3cm}p{8.2cm}}{Argument & Default & Rule}
\typerow{\texttt{convolution\_tolerance}}{\texttt{1e-12}}{Must lie in $(0,1)$; bound on the remaining mixture mass of the series}
\typerow{\texttt{max\_series\_terms}}{\texttt{100000}}{Must be positive; maximum number of series terms}
\typerow{\texttt{include\_steps}}{\texttt{False}}{With \texttt{True}, the report holds the list \texttt{steps}}
\tabend

\blockhead{Steps}
For each Gamma cell and day $k = 1,\ldots,T$:
\begin{enumerate}[nosep,label=\arabic*.]
  \item Keep the true damage as a list of independent Gamma terms (Section~\ref{sec:dyn_gamma}) and update it with the event of the day:
  \begin{itemize}[nosep]
    \item a mission adds a term with the exact rate of its increment;
    \item a repair multiplies the rate of the repairable terms by $1/(1-\rho)$, and removes them for $\rho = 1$; under $\ARDone$ the repaired terms join the frozen part of the anchor;
    \item a replacement starts a new list with the replacement term.
  \end{itemize}
  \item Treat an initial or replacement damage without a rate (\texttt{gamma\_beta\_0} or \texttt{gamma\_beta\_new} omitted) as a known constant $c$, not as a term. The tail is then $\Pr(\text{sum of the terms} > \tau - c)$, and $1$ if $c > \tau$.
  \item Compute the tail $\Pr(D_k > \tau)$ by the Moschopoulos series (with equal rates, the Gamma tail).
  \item Take as upper bound the partial sum plus the remaining mixture mass, which is at most \texttt{convolution\_tolerance}.
\end{enumerate}

\blockhead{Pass rule}
A day passes if:
\begin{itemize}[nosep]
  \item the upper bound is at most $\varepsilon_{i\ell} + \texttt{tolerance}$;
  \item the saved mean is at least $\mathbb{E}D_k - \texttt{tolerance}$;
  \item under $\ARDone$, the saved anchor is at least the exact mean of the frozen part minus \texttt{tolerance}.
\end{itemize}

\blockhead{Errors}
\tabstart{p{3.4cm}p{11.6cm}}{Exception & Raised when}
\rejrow{\texttt{RuntimeError}}{the series does not reach \texttt{convolution\_tolerance} within \texttt{max\_series\_terms} terms}
\tabend

\blockhead{Further arguments}
\tabstart{p{4.3cm}p{2.3cm}p{8.2cm}}{Argument & Default & Rule}
\typerow{\texttt{repetitions}}{\texttt{100000}}{Number of runs; must be positive}
\typerow{\texttt{random\_seed}}{\texttt{20260908}}{Seed of the generator; the same arguments give the same report}

\typerow{\texttt{confidence\_level}}{\texttt{0.95}}{Must lie in $(0,1)$}
\typerow{\texttt{batch\_size}}{\texttt{20000}}{Draws are made in batches of this many runs; must be positive}

\blockhead{Steps}
In each of \texttt{repetitions} runs:
\begin{enumerate}[nosep,label=\arabic*.]
  \item Draw the true damage of every Gamma cell. The initial damage, each mission increment and each replacement draw are independent Gamma variables with the means and rates of the inputs.
  \item Under $\ARDone$, take the initial damage as the sum of two independent terms with means $g^{\mu}_0$ (the anchor) and $\mu_0 - g^{\mu}_0$. A damage without a rate is the constant of its mean.
  \item Each day, apply the repair law to the sampled path: $D \leftarrow (1-\rho)\,D$ under $\ARDinf$; $D \leftarrow g + (1-\rho)(D - g)$, then $g \leftarrow D$, under $\ARDone$.
  \item On a replacement, draw the damage of the replacement part and, under $\ARDone$, set $g$ to it.
  \item After each day, record whether $D > \tau$.
\end{enumerate}

\blockhead{Definitions}
\begin{itemize}[nosep,leftmargin=1.5em]
  \item \textbf{Schedule failure}: a run in which some Gamma cell exceeds its threshold on some day.
  \item \textbf{Upper bound of a failure rate}: each failure rate (of the fleet, of a cell, of the worst day of a cell) comes with its one-sided Clopper--Pearson upper bound at \texttt{confidence\_level}. For $f$ failures in $n$ runs, it is the \texttt{confidence\_level}-quantile of the law Beta$(f+1,\ n-f)$, and $1$ if $f = n$.
\end{itemize}

\textbf{Pass rule.} \texttt{valid} is true if no target is given, or if the observed schedule failure rate is at most \texttt{maximum\_schedule\_failure\_rate}.

\section{Input File Schema}\label{sec:schema}

\subsection{Format Rules}

The formats are YAML (\texttt{.yaml}, \texttt{.yml}), JSON (\texttt{.json}) and HDF5 (\texttt{.h5}, \texttt{.hdf5}), chosen by the extension of the path in lower case; another extension raises an error.
One reader serves every function that takes an input path.
\begin{itemize}[leftmargin=1.5em]
  \item A file holds one mapping from the keys of Section~\ref{sec:inputs} to values, with the same keys and meaning in the three formats.
  \item An array is a nested list in YAML and JSON; the outermost list runs over the first axis of the shape (train, component, mission, day).
  \item YAML is read in the safe mode.
\end{itemize}

\subsection{HDF5 Layout}\label{sec:schema_hdf5}

An HDF5 file is flat: every key is an attribute or a dataset at the root.
The reader makes one entry of every root attribute and root dataset; a byte string is decoded as UTF-8, and a text attribute that begins with \texttt{\symbol{123}} or \texttt{[} is parsed as JSON.

\textbf{Input file.}
\begin{itemize}[leftmargin=1.5em]
  \item A scalar number, a flag or a single string is an attribute, or a dataset of shape~$()$; \texttt{H} is one integer or two integers.
  \item An array of numbers is a \texttt{float64} dataset with the shape of the key; a \texttt{null} entry is \texttt{NaN}.
  \item A selector array and \texttt{component\_names} are datasets of strings, or JSON text; a \texttt{null} entry of a selector is the empty string. \texttt{gurobi\_params} and \texttt{validation} are JSON text.
\end{itemize}

A number or a string is an attribute; an array of numbers is a \texttt{float64} dataset, with \texttt{NaN} kept; a list of strings, a mapping or a list of records is JSON text in an attribute; a key whose value is \texttt{None}, \texttt{objective} included, is not stored.
