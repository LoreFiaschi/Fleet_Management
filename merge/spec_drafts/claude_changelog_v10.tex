\emph{Change log (v1.0, merged package).}
The specification describes the package that merges the branches \texttt{lore}
and \texttt{main}, on \texttt{main}'s code base. It holds only the codebase and its
mathematical constructions; the reasons, proofs and sources are in the project
scoping document. The five degradation models are cell builders of one registry.
The repair laws are $\ARDinf$ (the whole degradation is reduced) and $\ARDone$
(the degradation since the last intervention is reduced). The horizon has a
transitory and an operating phase, $H = [H_1, H_2]$, and the loop row bounds the
full tracked state, anchors included. Every dynamics row is one-sided, in big-M
or indicator form. The rainflow model offers five tail bounds; the quadratic
reliability rows have an exact, a tangent and a piecewise-linear form. The
inverse Gaussian row is a cap from a conditional tail mean; the Gamma row is a
cap on the tracked mean that holds for any mix of rates. The reliability level,
the tangent point and the costs are set per cell. The horizon sweeps, the warm
starts, the schedule plot and the validators are specified. The input keys follow
one table, and unknown or old keys raise an error.
