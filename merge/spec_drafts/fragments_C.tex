\section{Input Specification}\label{sec:inputs}

An input is one mapping from key names to values.
A \emph{cell} is a pair $(i,\ell)$ of a train and a component.
The column \emph{Applies to} uses the abbreviations G (Gaussian), IG (inverse Gaussian), W (Wiener), Ga (Gamma), RF (rainflow) and, for a rainflow cell, Mk (Markov), Ca (Cantelli), Ho (Hoeffding), Be (Bernstein), Ch (Chernoff); \emph{all} is every cell.
A \emph{cell value} is a scalar, a list of $L$ numbers (one per component, copied to every train) or an $F \times L$ array; a scalar is copied to every cell.
A \emph{selector} has the same shapes with strings.
A \emph{profile} is defined in Section~\ref{sec:input_increments}; a \emph{flag} is \texttt{true} or \texttt{false}.
No other broadcasting is accepted.

At a cell where a key does not apply, an array entry may be \texttt{null} and the key may be omitted; where it applies, \texttt{null} is an error.
The exceptions are the three keys without a default, \texttt{v\_max\_user}, \texttt{gamma\_beta\_0} and \texttt{gamma\_beta\_new}: at these keys, \texttt{null} at a cell means that the key is not given at that cell.
A broadcast value (a scalar, a list, a profile without the axis $F$) is read only where the key applies.
A non-\texttt{null} entry of an array with one entry per cell ($F \times L$ array, or profile with the axes $F$ and $L$) at a cell where the key does not apply is ignored with a \texttt{UserWarning}; a selector entry there is still checked (Section~\ref{sec:consistency_checks}).
Key names and selector values are case sensitive; a key outside the tables raises an error (Section~\ref{sec:input_rejected}).
An integer key accepts a number with zero fractional part, such as \texttt{3.0}; it refuses any other number, such as \texttt{2.5}, and a flag.

\subsection{Increment Profiles and the Phase Lookup}\label{sec:input_increments}

A profile gives a parameter of the damage increment when train $i$ flies mission $j \in \{1,\ldots,M\}$, for component $\ell$.
Its canonical shape is $(F, L, M, H_*)$, with $H_* = H_2$ for an operating profile and $H_* = H_1$ for a transitory profile.
The parser accepts the shapes scalar, $(M)$, $(L, M)$, $(L, M, H_*)$, $(F, L, M)$ and $(F, L, M, H_*)$, and expands each of them to $(F, L, M, H_*)$ before any row is built (eager broadcasting); a missing axis is repeated.
An array whose shape fits both $(L, M, H_*)$ and $(F, L, M)$ is read as $(L, M, H_*)$.
\texttt{gamma\_beta} and \texttt{gamma\_beta\_trans} read a list as one rate per component and a two-dimensional array as one rate per cell; rates per mission have the shape $(F, L, M)$.

Let $p$ be an operating profile and $p^{\tr}$ the transitory profile of the same key, if given.
The value used on day $k \in \{1,\ldots,T\}$ is
\begin{equation}\label{eq:c_phase}
p^{\inc}_{i\ell jk} =
\begin{cases}
p^{\tr}_{i\ell jk} & k \le H_1 \text{ and } p^{\tr} \text{ is given},\\[2pt]
p_{i\ell j,\,((k-1) \bmod H_2) + 1} & k \le H_1 \text{ and } p^{\tr} \text{ is not given},\\[2pt]
p_{i\ell j,\,((k-H_1-1) \bmod H_2) + 1} & k > H_1.
\end{cases}
\end{equation}
Each profile key is looked up on its own.
The symbols $\mu^{\inc}_{i\ell jk}$, $v^{\inc}_{i\ell jk}$, $b^{\inc}_{i\ell jk}$ and $K^{\inc}_{i\ell jk}$ denote the values after the lookup.

\subsection{Consistency Checks}\label{sec:consistency_checks}

The solver validates all of the following before it builds the model.
A violation raises a \texttt{ValueError} whose message names the key and, for a cell value, the cell $(i,\ell)$.
A check of one model runs only at the cells of that model, on the entries where the key applies.
A non-strict inequality $a \le b$ (or $a \ge b$) passes when it holds up to $10^{-12}\max(1, |a|, |b|)$; a strict inequality has no tolerance.

\textbf{Keys, shapes and entries.}
\begin{itemize}[leftmargin=1.5em]
  \item Every key is in the tables of Section~\ref{sec:inputs}. The keys \texttt{F}, \texttt{M}, \texttt{H}, \texttt{model}, \texttt{tau}, \texttt{epsilon}, \texttt{rho}, \texttt{mu\_0}, \texttt{mu}, \texttt{C\_M}, \texttt{C\_R}, \texttt{C\_rep}, \texttt{C\_D} and the keys that each cell type requires (Section~\ref{sec:schema}) are present.
  \item Each value has one of the shapes of its table row; the last axis of an operating profile has $H_2$ entries and that of a transitory profile $H_1$; \texttt{component\_names} has $L$ entries.
  \item At a cell where a key applies, every entry is a finite number (a string for a selector); \texttt{null} is an error.
\end{itemize}

\textbf{Sizes and selectors.}
\begin{itemize}[leftmargin=1.5em]
  \item $F$, $M$ and $L$ are positive integers, and $F > M$. A given \texttt{L} equals the length of the component axis of \texttt{model} when \texttt{model} is a list or an array.
  \item Every entry of \texttt{component\_names} is a string that is not empty after blanks are removed.
  \item $H$ is an integer $\ge 1$, or a pair of integers $H_1, H_2 \ge 1$.
  \item \texttt{model} entries are \texttt{gaussian}, \texttt{inverse\_gaussian}, \texttt{wiener}, \texttt{gamma} or \texttt{rainflow}; \texttt{repair\_model} entries are \texttt{ard1} or \texttt{ardinf}, for every model.
  \item Every non-\texttt{null} entry of \texttt{bound\_method} is \texttt{markov}, \texttt{cantelli}, \texttt{hoeffding}, \texttt{bernstein} or \texttt{chernoff}, also at a cell that is not rainflow.
  \item Every non-\texttt{null} entry of \texttt{reliability\_impl} is \texttt{exact}, \texttt{tangent} or \texttt{pwl}, also at a cell whose row is linear (IG, Ga, Mk, Ch); there the value is ignored and the form \texttt{exact} is built. \texttt{encoding} entries are \texttt{bigm} or \texttt{indicator}.
  \item \texttt{penalty\_type} is \texttt{inf\_norm} or \texttt{quadratic}. If $C_D > 0$ and \texttt{penalty\_type} is \texttt{quadratic}, \texttt{reliability\_impl} is \texttt{exact} at every cell with a quadratic reliability row (G, W, and RF with Ca, Ho or Be); another value is an error.
\end{itemize}

\textbf{Reliability, repair and initial state.}
\begin{itemize}[leftmargin=1.5em]
  \item $\tau_{i\ell} > 0$ and finite.
  \item $\varepsilon_{i\ell} \in (0, 1)$, and $\varepsilon_{i\ell} < 0.5$ at G and W cells.
  \item $\rho_{i\ell} \in (0, 1]$.
  \item $0 \le \mu_{0,i\ell} < \tau_{i\ell}$.
  \item $v_0$, \texttt{support\_0} and $R_0$ are $\ge 0$; if \texttt{allow\_replacement} is \texttt{true}, so are \texttt{replacement\_mu}, \texttt{replacement\_v}, \texttt{support\_new} and $R^{\new}$.
  \item \texttt{tangent\_ref} $\in [0, 1)$ at cells with the form \texttt{tangent}; \texttt{pwl\_points} is an integer $\ge 1$.
  \item Starting anchors: $0 \le \texttt{anchor\_mu\_0} \le \mu_0$, $0 \le \texttt{anchor\_v\_0} \le v_0$, $0 \le \texttt{anchor\_R\_0} \le R_0$ and $0 \le \texttt{anchor\_K\_0} \le K_0$, at the cells that read them.
  \item If \texttt{replacement\_as\_new} is \texttt{true}, \texttt{replacement\_mu}, \texttt{replacement\_v}, \texttt{support\_new}, \texttt{R\_new} and \texttt{cgf\_new} are $0$ at every cell that reads them; the check does not run when the flag is \texttt{false}.
\end{itemize}

\textbf{Natural ranges and replacement states.}
\begin{itemize}[leftmargin=1.5em]
  \item Every initial value ($\mu_0$, $v_0$, $R_0$, $K_0$) and every replacement value ($\mu^{\new}$, $v^{\new}$, $R^{\new}$, $K^{\new}$; only if \texttt{allow\_replacement} is \texttt{true}) lies in $[0, M_s]$, with the natural range $M_s$ of its state: $\tau$ for a mean; $V_{\max} = \tau^2/\bigl(\Phi^{-1}(1-\varepsilon)\bigr)^2$ for the variance at G and W cells; $\varepsilon\tau^2/(1-\varepsilon)$ at Ca cells; $\tau(\tau - 2c)/(2\kappa)$ at Be cells, with $c = \kappa b/3$ and $\kappa = \ln(1/\varepsilon)$; $2\tau^2/\kappa$ for $R$ at Ho cells; $s\tau - \kappa$ for $K$ at Ch cells (Sections~\ref{sec:dyn_gaussian} to~\ref{sec:dyn_rainflow}). Hence every starting anchor lies in its range.
  \item If \texttt{allow\_replacement} is \texttt{true}, the replacement state $(\mu^{\new}, v^{\new}, R^{\new}, K^{\new})$ of every cell satisfies every row that holds on a replacement day, in the form built at the cell: the reliability row in the form of \texttt{reliability\_impl} (for \texttt{pwl}, the cap of the segment that contains $\mu^{\new}$), its side row, and $v^{\new} \le V^{\mathrm{user}}_{\max,i\ell}$ where \texttt{v\_max\_user} is given (Sections~\ref{sec:dyn_gaussian} to~\ref{sec:dyn_rainflow} and~\ref{sec:linear_forms}).
\end{itemize}

\textbf{Increments.}
\begin{itemize}[leftmargin=1.5em]
  \item $0 \le \mu^{\inc}_{i\ell jk} < \tau_{i\ell}$ for every mission $j$ and every day $k \in \{1,\ldots,T\}$.
  \item Where $\mu^{\inc}_{i\ell jk} = 0$, the values $v^{\inc}_{i\ell jk}$, $b^{\inc}_{i\ell jk}$ and $K^{\inc}_{i\ell jk}$ are $0$.
  \item $v^{\inc}_{i\ell jk}$, $b^{\inc}_{i\ell jk}$ and $K^{\inc}_{i\ell jk}$ are $\ge 0$. A transitory profile has its operating profile.
\end{itemize}

\textbf{Gaussian, inverse Gaussian, Wiener and Gamma cells.}
\begin{itemize}[leftmargin=1.5em]
  \item G: $\mu_0 \ge 3\sqrt{v_0}$, $\mu^{\inc}_{i\ell jk} \ge 3\sqrt{v^{\inc}_{i\ell jk}}$ for every mission $j$ and day $k$, and, if \texttt{allow\_replacement} is \texttt{true}, $\mu^{\new} \ge 3\sqrt{v^{\new}}$.
  \item IG: $\eta_{i\ell} > 0$.
  \item W: $\sigma_{i\ell} > 0$ and $v_{0,i\ell} \ge 0$.
  \item Ga: every entry of \texttt{gamma\_beta} and \texttt{gamma\_beta\_trans} is finite and $> 0$; \texttt{gamma\_beta\_0} and \texttt{gamma\_beta\_new}, where given, are finite and $> 0$.
  \item G, W, RF (Ca, Be) with \texttt{v\_max\_user} given: $V^{\mathrm{user}}_{\max,i\ell} > 0$, $V^{\mathrm{user}}_{\max,i\ell} \ge v_{0,i\ell}$ and, if \texttt{allow\_replacement} is \texttt{true}, $V^{\mathrm{user}}_{\max,i\ell} \ge v^{\new}_{i\ell}$.
\end{itemize}

\textbf{Rainflow cells.}
\begin{itemize}[leftmargin=1.5em]
  \item Be: $v^{\inc}_{i\ell jk} \le (b^{\inc}_{i\ell jk})^2/4$ for every mission $j$ and day $k$, $v_{0} \le (b^{0})^2/4$ and, if \texttt{allow\_replacement} is \texttt{true}, $v^{\new} \le (b^{\new})^2/4$.
  \item Be: $\tau_{i\ell} > 2\kappa\, b_{i\ell}/3$, with $\kappa = \ln(1/\varepsilon_{i\ell})$ and $b_{i\ell}$ the support constant of Section~\ref{sec:dyn_rainflow}.
  \item Be with the form \texttt{tangent}: $\texttt{tangent\_ref}\cdot\tau_{i\ell} < \sqrt{\tau_{i\ell}\,(\tau_{i\ell} - 2c_{i\ell})}$, with $c_{i\ell} = \kappa\, b_{i\ell}/3$; Be with the form \texttt{pwl}: $\tau_{i\ell}/(2P) < \sqrt{\tau_{i\ell}\,(\tau_{i\ell} - 2c_{i\ell})}$, with $P = \texttt{pwl\_points}$.
  \item Ch: \texttt{s\_chernoff} is given and $s_{i\ell} > \ln(1/\varepsilon_{i\ell})/\tau_{i\ell}$.
  \item Ch: $K^{\inc}_{i\ell jk} \ge s_{i\ell}\,\mu^{\inc}_{i\ell jk}$ for every mission $j$ and day $k$, $K_{0} \ge s\,\mu_{0}$, at \texttt{ard1} cells $g^{K}_{0} \ge s\,g^{\mu}_{0}$, and, if \texttt{allow\_replacement} is \texttt{true}, $K^{\new} \ge s\,\mu^{\new}$.
\end{itemize}

\textbf{Run options and costs.}
\begin{itemize}[leftmargin=1.5em]
  \item \texttt{objective\_mode} is \texttt{total}, \texttt{operating\_average} or \texttt{evaluation\_total}; in the last mode \texttt{evaluation\_horizon} is given. If \texttt{evaluation\_horizon} is given, in any mode, it is an integer $E > H_1$.
  \item \texttt{mip\_gap} $\ge 0$; \texttt{time\_limit}, \texttt{progress\_interval\_seconds} and \texttt{relaxation\_time\_limit} are $> 0$; \texttt{gurobi\_params} and \texttt{validation} are mappings; \texttt{fast}, \texttt{relaxation\_warm\_start}, \texttt{allow\_replacement} and \texttt{replacement\_as\_new} are flags.
  \item $C_M$, $C_D$, $C_{R,i\ell}$ and $C_{\mathrm{rep},i\ell}$ are finite and $\ge 0$.
\end{itemize}

\subsection{Rules for the Values}

\begin{itemize}[nosep,leftmargin=1.5em]
  \item \textbf{No solution}: if Gurobi found no solution, the solution arrays and the cost report are \texttt{null}, and so are \texttt{objective} and \texttt{mip\_gap}.
  \item \textbf{A solution found}: the arrays hold the best solution, and \texttt{status} tells how the solve ended.
  \item \textbf{Upper bounds}: the arrays \texttt{mu}, \texttt{v}, \texttt{R}, \texttt{K}, \texttt{g\_mu}, \texttt{g\_v}, \texttt{g\_R}, \texttt{g\_K} and \texttt{z} hold the tracked variables of the model, and are upper bounds (Section~\ref{sec:encoding}).
  \item \textbf{$z$ on transitory days}: in the mode \texttt{operating\_average}, $z$ is not built on the days of the transitory phase (Section~\ref{sec:repair_cost}). At a cell with $C_{R,i\ell} > 0$ the result holds, for those days, the value computed after the solve:
  \begin{equation}\label{eq:c_zpost}
    z_{i\ell k} = \begin{cases}
      \rho_{i\ell}\,\bigl(\mu_{i\ell,k-1} - g^{\mu}_{i\ell,k-1}\bigr) & \text{if } x^m_{i\ell k} = 1,\\
      0 & \text{otherwise,}
    \end{cases}
    \qquad k = 1, \ldots, H_1,
  \end{equation}
  with $\mu_{i\ell 0} = \mu_{0,i\ell}$, $g^{\mu}_{i\ell 0}$ the starting anchor, and $g^{\mu} \equiv 0$ under \texttt{ardinf}.
  \item \textbf{Value of $u$}: it is recomputed from \texttt{mu}, and reported also when $C_D = 0$:
  \begin{equation}\label{eq:c_u}
    u = \max_{i,k} \sum_{\ell=1}^{L} \mu_{i\ell k} \quad (\texttt{inf\_norm}),
    \qquad
    u = \max_{i,k} \sum_{\ell=1}^{L} \mu_{i\ell k}^2 \quad (\texttt{quadratic}).
  \end{equation}
  \item \textbf{Costs}: the cost $c_k$ of day $k$ and the phase costs $J_{\mathrm{init}}$, $J_{\mathrm{op}}$ are Equations~\eqref{eq:a_daycost} and~\eqref{eq:a_phases} (Section~\ref{sec:objective}) on the arrays of the result, with $z_{i\ell k} = 0$ where it is \texttt{NaN}.
  \item \textbf{Objective}: if the variable $u$ has no slack, \texttt{objective} equals, up to the tolerance of the solver, the key below for the mode in use; otherwise it is larger by $C_D$ times the slack.
  \begin{itemize}[nosep,leftmargin=1.5em]
    \item mode \texttt{total}: \texttt{J\_total};
    \item mode \texttt{operating\_average}: \texttt{operating\_objective};
    \item mode \texttt{evaluation\_total}: \texttt{evaluation\_objective}.
  \end{itemize}
\end{itemize}

  \item \textbf{Path checks}: the extension and the directory of the path are checked before the input file is read. The directory must exist (\texttt{FileNotFoundError}) and be writable (\texttt{PermissionError}).

\end{itemize}

\section{Input File Schema}\label{sec:schema}

\subsection{Format Rules}

The formats are YAML (\texttt{.yaml}, \texttt{.yml}), JSON (\texttt{.json}) and HDF5 (\texttt{.h5}, \texttt{.hdf5}), chosen by the extension of the path in lower case; another extension raises an error.
One reader serves every function that takes an input path.
\begin{itemize}[leftmargin=1.5em]
  \item A file holds one mapping from the keys of Section~\ref{sec:inputs} to values, with the same keys and meaning in the three formats.
  \item An array is a nested list in YAML and JSON; the outermost list runs over the first axis of the shape (train, component, mission, day).
  \item YAML is read in the safe mode.
\end{itemize}

\subsection{HDF5 Layout}\label{sec:schema_hdf5}

An HDF5 file is flat: every key is an attribute or a dataset at the root.
The reader makes one entry of every root attribute and root dataset; a byte string is decoded as UTF-8, and a text attribute that begins with \texttt{\symbol{123}} or \texttt{[} is parsed as JSON.

\textbf{Input file.}
\begin{itemize}[leftmargin=1.5em]
  \item A scalar number, a flag or a single string is an attribute, or a dataset of shape~$()$; \texttt{H} is one integer or two integers.
  \item An array of numbers is a \texttt{float64} dataset with the shape of the key; a \texttt{null} entry is \texttt{NaN}.
  \item A selector array and \texttt{component\_names} are datasets of strings, or JSON text; a \texttt{null} entry of a selector is the empty string. \texttt{gurobi\_params} and \texttt{validation} are JSON text.
\end{itemize}

\textbf{Output file.}
A number or a string is an attribute; an array of numbers is a \texttt{float64} dataset, with \texttt{NaN} kept; a list of strings, a mapping or a list of records is JSON text in an attribute; a key whose value is \texttt{None}, \texttt{objective} included, is not stored.
