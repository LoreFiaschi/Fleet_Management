# Records of the merge of `lore` and `main` (2026)

This folder records the merge of the branches `lore` and `main`. The merge was finished on 8 Nov 2026.
The files are kept for reference. They do not describe the current code.

## Content

| Path | What it holds |
|---|---|
| `lore-vs-main.md` | the comparison of the two branches (30 Sep 2026) |
| `decisions.md` | the user's choice for each difference between the branches |
| `code_plan.md` | the plan for the code of the merged package |
| `documents_plan.md` | the plan for the spec, the scoping document and the README |
| `spec_scoping_map.md` | the map of the 145 blocks moved from the spec to `scoping.tex` |
| `wp1_removals.md` | the removals and the repository hygiene of work packages 1 and 2 |
| `wp8_legacy_inventory.md` | the inventory of the earlier tests and scripts, work package 8 |
| `wp8_defects.md` | the defects found in work package 8 |
| `tightness_check.md` | the check of the tightness of the one-sided rows by full enumeration of schedules (8 Nov 2026) |
| `style_reference_spec_v03.tex` | version 0.3 of the spec, the style model for `spec/spec.tex` |
| `reports/` | four detailed comparison reports of the branches (areas A to D), cited by file and line |
| `analysis/` | the analyses of the Gamma and inverse Gaussian models, and `scripts/scoping_checks`, the scripts cited in `scoping.tex` |
| `step3/` | the merged review of the code against the spec (step 3) and the plan for the tighter loop rows |

## What is not here

The working records of the merge were removed. They are the plans of work packages 4 to 8, the progress
files and scripts of the agents, the spec fragments and builds, and the reports of steps 3 and 4.
They are in git history at commit 18c8a64 (branch `lore`).
